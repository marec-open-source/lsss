SchoolCategory

Name

SchoolCategory - Acoustic category for school

Synopsis

struct SchoolCategory {
  short Nation;
  short Platform;
  int   Survey;
  int   Object;
  short CategorySystem;
  int   Category;
};

Description

Code for acoustic category and in which category system that is used.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - Unique survey identification code. See the Survey table.
  • Object - see Scatter table.
  • CategorySystem - see SchoolCategorySystem table.
  • Category - Code for acoustic category (in given CategorySystem).
