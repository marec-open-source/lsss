StandardComment

Name

StandardComment - Standard comments frequently used

Synopsis

struct StandardComment {
  short Nation;
  short Platform;
  int   StandardComment;
  char  Text[200];
};

Description

This table contains a list of the standard comments provided for the current nation/platform combination.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Note that Platform = 0 means "national-wide" or "institute-wide" entry of the database table. Refer to the Platform database table.
  • StandardComment - Identification code for the comment. Refer to the ObservationComment database table.
  • Text - Free text containing the comment.
