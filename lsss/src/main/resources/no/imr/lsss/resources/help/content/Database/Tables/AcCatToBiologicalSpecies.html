AcCatToBiologicalSpecies

Name

AcCatToBiologicalSpecies - Coupling between acoustic categories and biological species

Synopsis

struct AcCatToBiologicalSpecies {
  short Nation;
  short Platform;
  int   AcousticCategory;
  int   BiologicalSpecies;
};

Description

This table contains coupling between the AcousticCategory and the BiologicalSpecies database tables. An acoustic category may be identical to a biological species, i.e. Cod, but it may also be a combination of acoustic categories where each is a single biological species, i.e. Ha/Co (Haddock/Cod), or it may be a subset of a biological species, e.g. 0-Herring (Zero group herring - herring less than 1 year), or a more generic acoustic category, e.g. "Large krill". The table should be updated at least when a new entry is inserted into AcousticCategory.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique identification code for observation platform. Note that Platform = 0 means "national-wide" or "institute-wide" entry of the database table. Refer to the Platform database table.
  • AcousticCategory - Acoustic category, i.e. "acoustic species". Refer to the AcousticCategory.
  • BiologicalSpecies - Unique identification code for biological species found in the BiologicalSpecies database table.
