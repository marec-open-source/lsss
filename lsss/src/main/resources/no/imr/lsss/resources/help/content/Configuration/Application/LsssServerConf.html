LSSS server configuration

LSSS includes a web server intended for remote control of LSSS via scripts. The scripts can be made in any language or framework that supports making HTTP requests. In particular, the LSSS server can be used by actions defined in packages.

Select the "Server active" checkbox and click the "Open web page" button to access the HTTP API documentation.

If several LSSS instances are started, then each instance needs a separate server port. The server port can be specified using the command line argument --server-port.

Example:

LSSS.bat --server-port=8001
