BB sample data export

This is an export of complex sample data after pulse compression.

For each region the rectangular bounding box in the time × range domain is exported. The bounding box is split into one or more blocks, each with constant sample distance. The 2D data arrays in each block are indexed as [timeIndex][rangeIndex].

If the available data does not cover the exported bounding box, then the value 0 is used instead.

Format

{
   "info" : {
      "exportType" : "BroadbandSampleData",
      ... // See Broadband export for details about the properties in the info block
   },
   "regions" : [ {
      "objectNumber" : 18,                                // The object number of this region
      "labels" : [ ],                                     // The labels assigned to this region
      "scrutiny": [ ... ],                                // See Broadband export for details
      "channels" : [ {
         "id" : "WBT 2-1 009072085343 ES200-7CD",         // The channel id
         "nominalFrequency" : 200000.0,                   // Nominal frequency for this channel
         "minRange" : 50.1,                               // The minimum range of the bounding box on this channel
         "maxRange" : 60.2,                               // The maximum range of the bounding box on this channel
         "blocks" : [ {
            "sampleDistance" : 0.00596,                   // The sample distance in this block
            "times" : ["2014-11-02T09:44:52.797Z", ... ], // The ping times in this block
            "re" : [ [ -1.30926E-4, ... ], ... ],         // The real part of the complex sample values, indexed re[timeIndex][rangeIndex]
            "im" : [ [ -5.55039E-5, ... ], ... ]          // The imaginary part of the complex sample values, indexed im[timeIndex][rangeIndex]
         }, {
            ...                                           // More blocks for this channel
         } ]
      }, {
         ...                                              // More channels for this region
      } ]
   }, {
      ...                                                 // More regions
   } ]
}

Notes

  • If a region spans more than one depth range for a given ping, then the enclosing depth range is used.

Changes

  • LSSS 2.8.0: Renamed "acousticCategories" to "scrutiny".
