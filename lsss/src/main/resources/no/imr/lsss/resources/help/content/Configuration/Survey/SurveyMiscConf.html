Miscellaneous configuration

This section contains miscellaneous survey settings.

  • Pelagic mode: If selected, then pelagic mode is used and the bottom echogram will be hidden.
  • Ping mapping: The horizontal axis of the echogram.
  • Seabed mounted echosounder: Whether the echosounder is mounted on the seabed, i.e., is pointing upwards.
  • Seabed mounted echosounder: Distance to seabed: The distance from the seabed mounted echosounder to the seabed.
  • Seabed mounted echosounder: Distance to surface: The depth of the seabed mounted echosounder.
  • Main frequency (Used in Map, FR, FileList): The main frequency. Used in the frequency response module when computing relative frequency response.
  • Depth of initial top boundary: The depth (in meters) to place the initial top layer boundary.
  • Offset from lower integration line to "detected" bottom: The distance above the coordinated bottom (in meters) to place the initial bottom layer boundary.
  • Min frequency for finding coordinated bottom: The minimum frequency to be used when computing the coordinated bottom.
  • Max frequency for finding coordinated bottom: The maximum frequency to be used when computing the coordinated bottom.
  • Shallowest acceptable depth relative to max depth: Used in the coordinated bottom calculation.
  • The maximum acceptable distance above the max depth: Used in the coordinated bottom calculation.
  • Preferred upper threshold: The default upper threshold for the echogram colorbar.
  • Preferred lower threshold: The lower threshold set when pressing the button below the echogram colorbar.
  • Additional lower thresholds: A comma-separated list of additional lower thresholds.
  • Show warning if not using preferred lower threshold: If the echogram is not using only the preferred lower threshold, a warning is shown next to the Store button in the Interpretation module.
  • Show warning if vertically zoomed: If the echogram is vertically zoomed, a warning is shown next to the Store button in the Interpretation module.
  • Use school categorization in interpretation: Determines which type of categorization to use for echogram display of categorization results. Also affects the assignment of sa from categorization results.
  • Minimum value for categorization probability/similarity: The minimum probability/similarity for a category to be used in the echogram.
  • School grow smoothing: Schools grown by clicking in echogram are smoothed by scaling up and down with this amount.
  • Compute school parameters: Whether to compute school parameters.
  • Recompute: Recomputes all school parameters.

Pelagic mode

The following table lists the differences between pelagic mode and full / bottom mode:

Feature Pelagic mode Full mode
The bottom echogram Hidden Visible
Pings with depth 0 Used as normal Displayed white on the echogram and not used in any calculations
Definition of the lower boundary for the initial layer BottomBoundaryOffset above the coordinated bottom Using 90% of the maximum depth of the pelagic echogram

Pelagic mode can also be selected in the echogram context menu.

Coordinated bottom

The following algorithm is used for finding the coordinated bottom:

  1. Use the bottom depths detected on all frequencies between MinFrequencyForBottom and MaxFrequencyForBottom.
  2. Find the maximum depth.
  3. Reject the depths shallower than the deepest of:
    • MinimumDepthThresholdFactor times the maximum depth.
    • MinimumDepthThresholdDistance above the maximum depth.
  4. The coordinated depth is computed from the remaining depths:
    1. If the depth for the MainFrequency is accepted, then it is used.
    2. Otherwise, the smallest of the remaining depths is used.

The coordinated bottom is used for defining the lower boundary of the initial layer. It is also displayed on the echogram.

ICES acoustic metadata

This section contains metadata used when generating database reports with Print format 25. This metadata is stored in the SurveyInfo database table.

The tables (Instrument, Calibration, DataAcquisition, DataProcessing) contain

  • Mandatory values indicated with bold column headers.
  • Optional values indicated with italicized column headers.

Some entries should have values from schemas with specific sets of codes. Click the button "Download schemas" to download the schema files listed below. The schema files will be stored in a subdirectory of MainDir configured in [Application configuration - Directories] and are shared across all surveys. The codes with descriptions are shown in the tooltip.

  • https://acoustic.ices.dk/Services/Schema/XML/AC_AcquisitionMethod.xml
  • https://acoustic.ices.dk/Services/Schema/XML/AC_DataAcquisitionSoftwareName.xml
  • https://acoustic.ices.dk/Services/Schema/XML/AC_DataProcessingSoftwareName.xml
  • https://acoustic.ices.dk/Services/Schema/XML/AC_OnAxisGainUnit.xml
  • https://acoustic.ices.dk/Services/Schema/XML/AC_ProcessingMethod.xml
  • https://acoustic.ices.dk/Services/Schema/XML/AC_StoredDataFormat.xml
  • https://acoustic.ices.dk/Services/Schema/XML/AC_Survey.xml
  • https://acoustic.ices.dk/Services/Schema/XML/AC_TransducerBeamType.xml
  • https://acoustic.ices.dk/Services/Schema/XML/AC_TransducerLocation.xml
  • https://acoustic.ices.dk/Services/Schema/XML/AC_TriwaveCorrection.xml
  • https://acoustic.ices.dk/Services/Schema/XML/EDMO.xml
  • https://acoustic.ices.dk/Services/Schema/XML/SHIPC.xml

The button "Reset values from data" will attempt to fill the tables with values from the beginning of the first file of the currently loaded data. If the KORONA button is selected, then the table DataProcessing will use preprocessed data from KoronaDataDir. The other tables will use original raw data from DataDir.

Not all entries of the ICES metadata are readily available in all data files. It is therefore recommended reviewing the values and making necessary corrections.

Some of the metadata values, such as TransducerDepth and Absorption, can vary during a survey. This variation will not be represented here, and suitably representative values should be chosen.
