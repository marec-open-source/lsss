Observation

Name

Observation - Data-stations and belonging navigation information.

Synopsis

struct Observation {
  short Nation;
  short Platform;
  int   Survey;
  int   ObservationDate;
  int   ObservationTime;
  short ObservationType;
  float Distance;
  float Latitude;
  float Longitude;
  float BottomDepth;
};

Description

The Observation database table contains information about all data-stations and corresponding navigation information.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - Unique survey identification code. See the Survey table.
  • Date - Date [YYYYMMDD] (UTC) of the observation.
  • Time - Time [hhmmssxx] (UTC) of the observation.
  • ObservationType - This parameter defines the type of observation made. Refer to the ObservationType table.
  • Distance - The vessel distance (in nautical miles) at the time of the observation measured from the vessel's logged distance at the start of the survey. If the vessel log shows NN nautical miles at the beginning of the survey, the Distance parameter will contain NN+X, where X is the sailed distance from the start of the survey.
  • Latitude - The latitude of the geographical position (in degrees) of the platform (often a ship) at the time of the observation.
  • Longitude - The longitude of the geographical position (in degrees) of the platform (ship) at the time of the observation.
  • BottomDepth - The detected bottom depth (in meters) at the time of the observation.
