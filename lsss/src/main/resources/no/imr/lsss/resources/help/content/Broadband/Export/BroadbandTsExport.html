BB TS(f) export

This is the export of TS-frequency spectra per ping for targets detected in the depth ranges defined by the active regions, as displayed by the BB TS(f) view.

Format

{
   "info" : {
      "exportType" : "BroadbandTS",
      ... // See Broadband export for details about the properties in the info block
   },
   "pings" : [ {
      "number" : 411,                             // The ping number
      "time" : "2014-11-02T09:44:52.797Z",        // The time of this ping
      "channels" : [ {
         "id" : "WBT 2-1 009072085343 ES200-7CD", // The channel id
         "nominalFrequency" : 200000.0,           // Nominal frequency for this channel
         "minFrequency" : 160012.22,              // Minimum frequency
         "maxFrequency" : 250000.0,               // Maximum frequency
         "numFrequencies" : 2949,                 // The number of evenly spaced frequencies between the minimum and maximum frequencies inclusively
         "targets" : [ {                          // The targets found in this ping
            "tsc" : [ -41.23, ...  ],             // numFrequencies number of beam compensated TS values
            "range" : 10.507,                     // Range from transducer for the sample with the peak value
            "alongshipAngle" : -0.37,             // Alongship angle for the sample with the peak value at nominal frequency
            "athwartshipAngle" : 0.49             // Athwartship angle for the sample with the peak value at nominal frequency
         }, {
            ...                                   // More targets for this channel
         } ]
      }, {
         ...                                      // More channels in this ping
      } ]
   }, {
      ...                                         // More pings
   } ]
}

Notes

  • TS values are beam compensated.
  • Range and angles are calculated at sample with peak value.
  • Angles are calculated at nominal frequency.

Changes

  • LSSS 2.3.0: Renamed "ts" to "tsc".
