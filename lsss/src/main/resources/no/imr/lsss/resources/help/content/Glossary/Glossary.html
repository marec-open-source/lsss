Glossary

Area backscatter coefficient: The volume backscatter coefficient integrated over a depth range, multiplied with the scaling factor 4 π (1852)2.

Echogram: A graphical presentation of a sequence of pings in a 2D image.

EK60: An echo sounder system by Simrad, designed for fishery research.

Layer boundary: A boundary separating a layer from other layers.

Module: An LSSS component that performs computation and/or displays information about the echo sounder data or other data. It can loosely be thought of as a common term for views and overlays.

Overlay: A graphical information overlay for the echogram view or the map view.

Pelagic mode: Running LSSS without using the detected bottom as a basis for the deepest layer boundary. See [Survey Configuration - Miscellaneous].

Ping: An acoustic pulse, usually concentrated in a cone in front of the transducer. The time between transmission and reception of the pulse is used to decide the distance to a target. In the context of LSSS, a ping usually refers to the data collected in the reception process. If multiple frequencies are used, the different transducers are usually synchronized. If so, a ping means the ensemble of all the receptions for all the frequencies sharing the same timestamp (time of transmission).

Platform: A common term for the observing object. It can, for example, be a ship or a buoy.

Region: An isolated area of an echogram. A survey can be divided into regions as an aid in the interpretation process. See [Working with LSSS - Working with regions].

sA: See area backscatter coefficient

Survey: A collection of data gathered during a limited time period and a limited geographical area. In the database, each survey is assigned a unique survey identifier consisting of nation, platform and a survey code.

sv: See volume backscatter coefficient.

View: One of the sub-windows in LSSS. Examples are the echogram view, the map view and the frequency response view.

Volume backscatter coefficient: A measure of the backscattering of targets and inhomogeneities in a volume.

WMS: Short for Web Map Service. A web service that dynamically produces map images on request from clients.
