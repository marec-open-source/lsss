Broadband export

The broadband exports use the JSON format. The general structure is:

Format

{
   "info" : {
      "exportType" : "BroadbandSv",                // The type of this export
      "exportTime" : "2015-09-07T13:47:17Z",       // Time of export in ISO 8601 format
      "lsssVersion" : "1.9.2",                     // The version of LSSS used to generate the export
      "formatLastChangedInLsssVersion" : "1.9.2",  // The version of LSSS where the format of this type of export was last changed
      "parameters" : {                             // Parameter settings used during the export
         "parameter name": "value",
         ...
      },
      "units" : {                                  // Units of the exported values
         "export value name": "unit",
         ...
      },
      "comments" : [ "comment", ... ],
   },

   // Exported data

   "channelInfo" : [ {                             // Summary information with channel parameters
      "id" : "WBT 2-1 009072085343 ES200-7CD",
      "parameters" : [ {                           // There will be multiple entries if some parameters change value
         "startTime" : "2014-11-02T09:45:58.663Z",
         "endTime" : "2014-11-02T09:46:26.630Z",
         "nominalFrequency" : 200000.0,
         "minFrequency" : 160000.0,
         "maxFrequency" : 260000.0,
         "transmitPower" : 120.0,
         ...
      } ]
    } ]
  }
}

Scrutiny

Some exports include assignments to acoustic categories for each region. The structure of this information is: 


   "scrutiny" : [ {                                    // Array of channels
      "channelId" : "WBT 2-1 009072085343 ES200-7CD",
      "categories" : [ {                               // Array of assignments to categories for this channel
        "id" : 12,
        "initials" : "HERR",
        "assignment" : 0.379
      }, {
         ...                                           // More acoustic categories for this channel
      } ]
   }, {
      ...                                              // More channels
   } ]

Notes

Note that the format of and definitions in all the export formats may change in future versions of LSSS.
