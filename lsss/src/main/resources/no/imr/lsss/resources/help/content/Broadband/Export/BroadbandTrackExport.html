BB TS(f) tracks export

This is the export of tracks detected by the KORONA tracking module. TS is calculated using the FrequencyWindowing and FrequencyResolution configured for the BB TS(f) view. Only the tracks where all peak samples are contained in the selected regions are included in the export.

For each track, the properties "pingNumber" - "peakDepth" and "minFrequency" - "tsc" are arrays over the pings that the track consists of. If a channel is missing for a particular ping, then the value NaN is used.

Format

{
   "info" : {
      "exportType" : "BroadbandTracks",
      ... // See Broadband export for details about the properties in the info block
   },
   "tracks" : [ {
      "labels" : [ "labelA", ... ],                                             // Labels
      "pingNumber" : [ 757, 758, ... ],                                         // Ping number
      "time" : [ "2014-11-02T09:46:04.470Z", "2014-11-02T09:46:04.678Z", ... ], // Time
      "longitude" : [ 5.48296867, 5.48296828, ... ],                            // Longitude
      "latitude" : [ 59.99294278, 59.99294288, ... ],                           // Latitude
      "heading" : [ 213.15, 213.09, ... ],                                      // Heading
      "heave" : [ 0.0, 0.10, ... ],                                             // Heave
      "pitch" : [ 0.54, 0.55, ... ],                                            // Pitch
      "roll" : [ 0.87, 0.88, ... ],                                             // Roll
      "minDepth" : [ 13.255, 13.255, ... ],                                     // Minimum depth of the track on the detection channel
      "maxDepth" : [ 13.279, 13.279, ... ],                                     // Maximum depth of the track on the detection channel
      "peakDepth" : [ 13.267, 13.267, ... ],                                    // Depth of the peak sample on the detection channel
      "channels" : [ {
         "id" : "WBT 2-1 009072085343 ES200-7CD",      // The channel id
         "nominalFrequency" : 200000.0,                // Nominal frequency
         "minFrequency" : [ 165000.0, 165000.0, ... ], // Minimum frequency
         "maxFrequency" : [ 250000.0, 250000.0, ... ], // Maximum frequency
         "numFrequencies" : [ 86, 86, ... ],           // The number of evenly spaced frequencies between the minimum and maximum frequencies inclusively
         "peakRange" : [ 13.267, 13.267, ... ],        // Range of the peak sample
         "fftDistanceBefore" : [ 0.012, 0.012, ... ],  // Distance above peak included in FFT
         "fftDistanceAfter" : [ 0.012, 0.012, ... ],   // Distance below peak included in FFT
         "alongshipAngle" : [ 0.95, 0.71, ... ],       // Alongship angle for the sample with the peak value at nominal frequency
         "athwartshipAngle" : [ -1.71, -1.41, ... ],   // Athwartship angle for the sample with the peak value at nominal frequency
         "x" : [ 0.22, 0.163, ... ],                   // Alongship position of peak sample, relative to transducer
         "y" : [ -0.396, -0.325, ... ],                // Athwartship position of peak sample, relative to transducer
         "z" : [ 13.259, 13.262, ... ],                // Vertical position of peak sample, relative to transducer
         "tsc" : [ [ -76.96, -80.31, ... ], ... ]      // numFrequencies number of beam compensated TS values
      }, {
         ...                                           // More channels for this track
      } ],
   }, {
      ...                                              // More tracks
   } ]
}

Notes

  • TS values are beam compensated.
  • Angles are calculated at sample with peak value at nominal frequency.
  • Angles are not included for visually edited parts of tracks.

Changes

  • LSSS 2.3.0: Renamed "ts" to "tsc".
