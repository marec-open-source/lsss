Regions menu

This menu is part of the menu bar.

Select next visible region

Select the next visible region.

Select all visible regions

Select all visible regions.

Select all visible regions with total assignment not 100% on current frequency

Select all visible regions where the total assignment is ≠ 100% on the current frequency. This is a useful function to check that all regions are scrutinized prior to saving to the database.

Select all visible regions with total assignment not 100% on storable frequencies

Select all visible regions where the total assignment is ≠ 100% on storable frequencies. This is a useful function to check that all regions are scrutinized prior to saving to the database.

Select visible regions with acoustic category

Select all visible regions that are scrutinized as specified category (e.g. mackerel).

Region labels

Add labels to regions. Select regions based on labels.

Reset interpretation...

Reset interpretation, i.e. discard all allocated categories and set layer-lines to default. In surface-mode (i.e. bottom window active), the lower integration line is drawn according to the detected bottom. Note that the bottom detected by the echosounder and by the preprocessor is in general slightly different. If the echogram mode is set to pelagic mode, the lower integration line is drawn at a predefined depth.

Exclude pings with low speed...

Automatically exclude pings with low speed. The excluded distances are expanded until the speed is stabile.

Merge neighbouring layers with same interpretation

Merge visible layers with the same interpretation and the same set of labels.

Set upper boundary from range

Set the upper integration line from a specified range.

Set upper boundary from threshold

Set the upper integration line in the visible part of the echogram based on the colours. If the noise threshold is set so that only the blind zone near the transducer is visible, the upper integration line will be drawn to follow the blind zone.

Set lower boundary from threshold

Set the lower integration line in the visible part of the echogram based on the colours. If the noise threshold is set so that only the bottom is visible, the lower integration line will be drawn to follow the bottom.

Set lower boundary from coordinated bottom

Set the lower integration line in the visible part of the echogram by using the detected/coordinated bottom and the configured offset from bottom.

Set lower boundary from bottom on current frequency

Set the lower integration line in the visible part of the echogram by using the detected bottom in the current frequency and the configured offset from bottom.

Delete data above lower integration line and below bottom on current frequency

Applies frequency-dependent deletion to data that is above the lower integration line and below the detected bottom on the current frequency. The deletion is applied to the current frequency in the visible ping range.

Delete assignments on other frequencies

Delete assignments for selected regions on other frequencies than the one that is currently active.

Delete assignments on all frequencies

Delete assignments for selected regions on all frequencies.

School visualizer dialog...

Shows a dialog for exploring school parameters.

Category editor...

See categorization library in KORONA manual.
