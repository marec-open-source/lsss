BB bottom data export

This is an export of complex sample data after pulse compression.

The area exported is per ping [bottom depth - delta above, bottom depth + delta below]. The area is split into one or more blocks, each with constant sample distance. The 2D data arrays in each block are indexed as [timeIndex][rangeIndex].

If the available data does not cover the exported area, then the value 0 is used instead.

Format

{
   "info" : {
      "exportType" : "BroadbandBottomData",
      ... // See Broadband export for details about the properties in the info block
   },
   "channels" : [ {
      "id" : "WBT 2-1 009072085343 ES200-7CD",         // The channel id
      "nominalFrequency" : 200000.0,                   // Nominal frequency for this channel
      "blocks" : [ {
         "sampleDistance" : 0.00596,                   // The sample distance in this block
         "times" : ["2014-11-02T09:44:52.797Z", ... ], // The ping times in this block
         "depths" : [103.403, ... ],                   // Bottom depths
         "re" : [ [ -1.30926E-4, ... ], ... ],         // The real part of the complex sample values, indexed re[timeIndex][rangeIndex]
         "im" : [ [ -5.55039E-5, ... ], ... ]          // The imaginary part of the complex sample values, indexed im[timeIndex][rangeIndex]
      }, {
         ...                                           // More blocks for this channel
      } ]
   }, {
      ...                                              // More channels
   } ]
}
