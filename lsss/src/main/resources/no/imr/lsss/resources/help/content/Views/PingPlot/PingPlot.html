Ping plot

This view plots an echogram variable against depth for the ping corresponding to the mouse position. The plot can either use the same variable as is shown in the echogram, or be configured to show a separate variable. If the mouse is in the bottom echogram, then z is used as the vertical axis instead of depth.

Settings

  • Ping radius: The number of previous and subsequent pings to be displayed along with the current ping (mouse position in echogram). In total, 2 × PingRadius + 1 curves are shown.
  • Use threshold range: This option determines the extent of the horizontal axis. If this option is selected then the upper and lower thresholds for the chosen variable are used, if not then the configured min/max limits for the chosen variable are used.
  • Only selected regions: If this option is selected, then only samples in selected regions are plotted.
  • Same variable as echogram: If this option is selected, then the same variable is used as is shown in the echogram. Normally the echogram variable is Sv, but a different variable can be selected in the colorbar advanced menu.
  • Variable: The variable to show. This option is only enabled if Same variable as echogram is deselected. The choices available here are the same as in the colorbar advanced menu.

    Note that all variables have individual min/max limits and upper/lower thresholds. This means that the limits and thresholds for selected variable in this plot may not correspond to what is shown in the colorbar.
