Area

Name

Area - Areas of the seas

Synopsis

struct Area {
  short Nation;
  int   Area;
  char  AreaName[80];
};

Description

This table contains names of sea areas, e.g. Barents Sea or Norwegian Sea.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Area - Unique identification code for area.
  • AreaName - Name of the sea area.
