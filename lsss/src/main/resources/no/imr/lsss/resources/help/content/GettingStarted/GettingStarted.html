Getting started with LSSS

Loading files

The data files to load are selected in the 'Data files' section of the survey configuration dialog. This dialog can be opened through the 'File' menu. Data files, or a directory containing data files, can also be dragged from a file browser into the echogram.

Note that all raw-files must have corresponding idx-files. Idx-files can be created by LSSS from the 'Data files' section of the survey configuration dialog if they are missing. If bot-files are missing, LSSS can only be run in pelagic mode.

If there are corresponding work files in the WorkDir folder specified in the 'Data files' section of the survey configuration dialog, then the saved interpretation (regions and species interpretation) will also be loaded.

Working mode

There are four different working modes. The toolbar buttons may be used to select working mode. Alternatively, press the Tab (Shift + Tab) to go to the next (previous) mode. If a mode has sub-modes, then Spacebar (Shift + Spacebar) selects the next (previous) sub-mode.

The delete, zoom and add modes are onetime operations. Double-click on the corresponding toolbar button to apply one of these modes several times.

Edit mode  

The edit mode is context-sensitive. The action depends on the mouse location.

  • Click the left mouse button in a region to select that region.
  • Drag the mouse over several regions to select the regions intersecting the drawn rectangle.
    • Hold down Ctrl to toggle selection of the regions intersecting the draw rectangle.
    • Hold down Shift to additionally select the regions intersecting the draw rectangle.
  • Press down the left button near a region boundary and drag the mouse to edit that region boundary.
  • Press down the left button at the center marker of a school region and drag the mouse to move that region.

This mode is described in more detail in the section on regions.

Delete mode  

This mode is for frequency-dependent deletion of data. Deleted data is marked with a semi-transparent gray overlay.

  • Press Spacebar to toggle between delete and undo delete.
  • Press Ctrl + Spacebar to change the shape of the deletion area.
  • Use Plus and Minus keys to change the size of the deletion area.

Zoom mode  

Zoom in:

  • Click the left mouse button to zoom in horizontally around the mouse position.

Zoom out:

  • Click the middle mouse button (or Alt + Left button) to zoom out both horizontally and vertically around the mouse position.
  • Press down the Ctrl key and click the middle button to zoom out maximally both horizontally and vertically. Pressing 'Home' on the keyboard has the same effect.

Press Spacebar to change between zoom and pan.

Zoom in to a rectangular area:

  • Press the left mouse button and drag the mouse to draw a rectangular area.
  • The shape of the area may be automatically expanded vertically or horizontally depending on whether the initial mouse movement is horizontal, vertical or diagonal.
  • Press Spacebar to change the automatic expansion of the area.
  • Release the mouse button to zoom in to the drawn area.
  • Press Esc to cancel the zoom.

Add mode  

  • Click the left mouse button to insert a new layer boundary.
  • Press Spacebar to change between inserting horizontal and vertical layer boundaries and school regions.

This mode is described in more detail in the section on regions.

Echogram navigation

Navigation in addition to the zoom mode:

  • Press Ctrl + arrow keys to pan. Ctrl + Up and Down arrow keys operate only on the echogram in which the mouse is located.
  • Press Ctrl + Alt + Left (Right) to go to the previous (next) location.
  • Use the mouse scroll wheel to zoom horizontally. Press Shift to zoom vertically and Ctrl to zoom in both directions.

See also the chapter about the echogram.

Data loading mode

There are two data loading modes:

  • BROWSE: Only enough pings are loaded to cover the echogram window.
  • DETAIL: All pings in the current range are loaded.

NB: If DETAIL mode is used on a too large interval, the system may run out of memory.

The data loading mode may be changed by clicking on the data loading mode indicator on the status bar or through the context menu of the echogram view.
