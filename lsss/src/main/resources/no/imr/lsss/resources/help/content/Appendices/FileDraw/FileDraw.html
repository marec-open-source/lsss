File draw

Data directory is configured in [Survey configuration - Data files].

The data is shown as an overlay on the echogram.

File format

A data file consists of lines specifying points as [Date] [Time] [Depth]:

  1. Date as yyyymmdd in UTC
  2. Time as hhmmssXXX in UTC. XXX means milliseconds and is optional.
  3. Depth in meters

Example

20001214 160237 150.3
20001214 160300 160
20001214 160630 170.7
20001214 160720 170.5
20001214 160807 180.1
20001214 160837 165.1
20001214 160901 150.2
20001214 161007 140.4
