Purpose

Name

Purpose - Purpose of scrutinizing acoustic category on survey.

Synopsis

struct Purpose {
  short Nation;
  short Platform;
  int   Survey;
  int   AcousticCategory;
  short Purpose;           //OLD:SpeciesPurpose; char Purpose
};

Description

This table contains the purpose code for the acoustic categories used in the current survey.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - Unique survey identification code. See the Survey database table.
  • AcousticCategory - Unique identification code for acoustic category. Refer to the AcousticCategory database table.
  • Purpose - Identification code assigning the requested purpose (priority) to one or more species. The purposes of scrutinizing this acoustic category are as follows:
    1 = Most important category. This is the main (or one of the few main) acoustic category scrutinized on this survey. There are experts on the species represented by the acoustic category at the observation platform. The survey is designed to cover the residential area of the stock. The biological sampling is optimized for the species represented by the acoustic category, e.g. for the purpose of using the acoustic data (in Scatter and ScatterData) to estimate fish stock abundance.
    2 = Not very important category. The biological sampling is not optimized for the species represented by the acoustic category, or the survey area only covers parts of the residential area of the stock. The acoustic data may with some care be used as support information to acoustic data from other cruises to calculate fish stock abundance.
    3 = Unimportant category. The acoustic category is used as a collector for "the rest of the acoustic data". Typical acoustic categories marked by Purpose = 3 are "Others", "Mix of pelagic fish", "Mix of bottom fish". The acoustic category may not be used to estimate abundance.
    0 = Unknown importance. Means that the category purpose code has not been assigned or is unknown as for some historical data.
