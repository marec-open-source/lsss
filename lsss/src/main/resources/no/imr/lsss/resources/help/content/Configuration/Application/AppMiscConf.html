Miscellaneous configuration

This section contains miscellaneous application settings.

  • On application start: What to do when starting LSSS.
  • On survey open: What to do when opening a survey.
  • Map URL: The Map WMS URL is used by the map view to produce the background map image. Example: https://kart.hi.no/data/hi_basemap/wms?.
  • Map layers: The layers requested from Map URL. This should be a comma-separated list of identifiers.
  • Select layers...: Downloads WMS capabilities and select layers.
  • Reset: Resets Map URL and Map layers to their default values.
  • Max pings: The maximum number of pings that will be read in DETAIL mode.
  • Ping loading: The strategy for how pings should be read from file:
    • LEFT_TO_RIGHT: The pings are read from left to right. Arguably the fastest way to read the pings, but the user will have to wait for a while before an impression of the echogram appears.
    • RANDOM: The pings are read in a completely random sequence.
    • LONGEST_GAP_LEFT_TO_RIGHT: The pings are read so that the longest gap in the echogram is filled first. The gaps of equal length are ordered from left to right.
    • LONGEST_GAP_RANDOM: The pings are read so that the longest gap in the echogram is filled first. The gaps of equal length are ordered randomly.
  • Preload: If checked, the system will preload pings in the next segment in the background.
  • Preload preprocessed: If checked, the system will preload pings from the preprocessed data files in the background if available. This preloading will be started after preloading the next segment is completed. If the preprocessed data is activated then the original data will be preloaded.
  • Use English: If checked, English initials and names are used for acoustic categories in LSSS. Otherwise, the native initials and names are used. This setting also affects the naming of acoustic categories in the reports.
  • Vertical scrollbar: If checked, then a vertical scrollbar is shown in the echogram.
