Display organization

The basic layout of the LSSS main frame is illustrated in the picture below:

The main frame consists of the following components:

  • The menu bar.
  • The toolbar.
  • The echogram, consisting of a pelagic echogram and a bottom echogram.
  • The floatable views along the bottom and right edges of the frame.
  • The status bar.

The menu bar

The main menus are laid out as follows:

  • File: Functionality for creating/opening/saving surveys.
  • View: Functions for configuring the appearance of the main frame.
  • Go: Functionality for navigating in the echogram. The echogram context menu has more functions.
  • Regions: Functionality for working with regions.
  • Tracks: Functionality for working with tracks.
  • Window: Options for hiding / showing each of the floatable views.
  • Help: Online help system (this document).

Floatable views

The smaller frames along the bottom and right sides of the main frame are called floatable views. Each of these views has three possible states:

  • Docked: When it is visible and attached to the main frame. A docked window can be made floating using the button, and hidden using the button.
  • Floating: When it is visible and displayed in a separate window. A floating window can be docked by closing the window.
  • Hidden: When it is not visible. A hidden view can be made visible via the window menu.

The following buttons are shown in the upper part of the view:

  • This button launches the configuration dialog for this module. This button is only displayed if the view has any configuration parameters.
  • This button displays a menu with more actions.
  • This button makes the view floating.
  • This button makes the view hidden.

Each view is described in the chapter on views.

The status bar

The status bar shows the following information:

  • Status text: A short description of the current system status.
  • Survey information: Nation / Platform name / Survey name (survey number)
  • Data loading mode:
    BROWSE: Only enough pings required for displaying the echogram image are loaded.
    DETAIL: All pings are loaded.
    Click to change.
  • Database status:
    DB: none if the database is not connected.
    DB: idle if the database is connected.
    DB: busy if there is currently communication with the database.
  • Ping loading status:
    The number shows the percentage of the available pings that will be loaded. In DETAIL mode, this is always 100%.
    The progress indicator shows how many of the required pings that have been loaded.
