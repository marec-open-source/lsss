ObservationComment

Name

ObservationComment - Comment to observation

Synopsis

struct ObservationComment {
  short Nation;
  short Platform;
  int   Survey;
  int   ObservationDate;
  int   ObservationTime;
  short ObservationType;
  int   StandardComment;
  int   Mantissa;
  int   Exp;
  char  Text[200];
};

Description

ObservationComment contains the mapping link between observations and comments.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - Unique survey identification code. See the Survey table.
  • Date - Date of event or observation. Refer to the Observation database table.
  • Time - Time of day of event or observation. Refer to the Observation database table.
  • ObservationType - Code for which type of observation made. Refer to the Observation database table.
  • StandardComment - Comment code. Refer to the StandardComment database table. If the code value is 0, the comment is defined in the Text parameter.
  • Mantissa - See the CommentExp parameter below.
  • Exp - Any comment may have a specific value assigned to it. This value can be any number, and the value stored as two different parameters in the ObservationComment database table; Mantissa and Exp. Value = Mantissa × 10Exp. The conversion from the assigned value to the two parameter values is performed automatically when the data is stored to the database.
  • Text - Free text to enter comment. Note that maximum size is 200 characters. This parameter is empty if a standard comment is used (StandardComment parameter > 0).
