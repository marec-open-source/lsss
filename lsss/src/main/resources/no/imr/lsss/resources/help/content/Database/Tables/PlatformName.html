PlatformName

Name

PlatformName - Information about observation platforms

Synopsis

struct PlatformName {
  short Nation;
  short Platform;
  int   FirstValidDate;
  int   LastValidDate;
  char  PlatformName[80];
};

Description

This table contains the mapping from the name of the observation platform to nation code and platform code. The observation platform is often a ship.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Platform identification code. This information must be unique for the corresponding Nation code. Refer to the Platform database table.
  • FirstValidDate - [YYYYMMDD] First date the observation platform was operational.
  • LastValidDate - [YYYYMMDD] Last date the observation platform was operational.
  • PlatformName - Name of observation platform, e.g. "G.O. Sars".

Related topics

Database

Related database tables

The database table PlatformType contains info about types of platforms.
The database table PlatformCodes contains platform codes in other coding systems.
