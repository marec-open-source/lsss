Data correction

The data files with echosounder sample data sometimes contain errors and inconsistencies. Some of these are corrected automatically by the system. The files with errors are marked in the status columns in the table in [Survey configuration - Data files] with the symbol

  •   or     if an error is corrected.
  •   or     if an error is not corrected.

Corrected errors

Error Correction
Missing index datagram within an idx-file The previous index datagram is duplicated
Missing bot file Bottom datagrams with depth 0 are used
Too few bottom datagrams in a bot-file Bottom datagrams with depth 0 are appended
Datagram format error Datagram is ignored
Gap in ping numbering between two consecutive files Pings with no data are inserted
Decrease in ping numbering between two consecutive files The ping numbering of the second file is shifted
Decrease in vessel distance within the same file The vessel distance in a ping is forced to be larger than or equal to the vessel distance in the previous ping
Decrease in vessel distance between two consecutive files The vessel distance of the second file is shifted
Non-increasing time from one ping to the next The time of the second ping is modified. The modified time is found by linear interpolation from the neighbouring pings weighted by vessel distance. If linear interpolation is not applicable, then the modified time is set to the time of the previous ping plus 1 NT date unit = 100 nanoseconds.

Errors not corrected

Error Consequence
Missing idx file The file is not used
Non-increasing time between two consecutive files The second file is not used
Different sets of frequencies in two files The second file is not used
