BB Sv(f) export

This is the export of Sv-frequency spectra per ping from the depth ranges defined by the active regions, as displayed by the BB Sv(f) view.

Format

{
   "info" : {
      "exportType" : "BroadbandSv",
      ... // See Broadband export for details about the properties in the info block
   },
   "regions" : [ {
      "objectNumber" : 18,                           // The object number of this region
      "labels" : [ ],                                // The labels assigned to this region
      "scrutiny": [ ... ],                           // See Broadband export for details
      "pings" : [ {
         "number" : 411,                             // The ping number
         "time" : "2014-11-02T09:44:52.797Z",        // The time of this ping
         "channels" : [ {
            "id" : "WBT 2-1 009072085343 ES200-7CD", // The channel id
            "nominalFrequency" : 200000.0,           // Nominal frequency for this channel
            "minFrequency" : 160012.22,              // Minimum frequency
            "maxFrequency" : 250000.0,               // Maximum frequency
            "numFrequencies" : 2949,                 // The number of evenly spaced frequencies between the minimum and maximum frequencies inclusively
            "sv" : [ -61.28, ...  ],                 // numFrequencies number of Sv values
            "depth" : 10.507                         // Depth for the center
         }, {
            ...                                      // More channels in this ping
         } ]
      }, {
         ...                                         // More pings for this region
      } ]
   }, {
      ...                                            // More regions
   } ]
}

Notes

  • Depth is for the centre.
  • If a region spans more than one depth range for a given ping, then Sv is computed for each depth range and then averaged.
  • If a depth range is too short to compute Sv, then the error property is set and that depth range is ignored.

Changes

  • LSSS 1.11.0: Added assignments to acoustic categories.
  • LSSS 2.8.0: Renamed "acousticCategories" to "scrutiny".
