AcousticCategoryComposite

Name

AcousticCategoryComposite - List of composite acoustic categories and the members of each category.

Synopsis

struct AcousticCategoryComposite {
  short Nation;
  short Platform;
  int   AcousticCategory;
  int   AcousticCategoryMember;
};

Description

This table contains the name of the composite acoustic categories and which non-composite acoustic categories are allocated as "members" of the composite acoustic category.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique identification code for observation platform. Note that Platform = 0 means "national-wide" or "institute-wide" entry of the database table. Refer to the Platform database table.
  • AcousticCategory - Code of the acoustic category, which of course is composite (e.g. code for group of species). Refer to the AcousticCategory database table.
  • AcousticCategoryMember - Code of the non-composite acoustic category (e.g. code for species) defined as a member of the composite category given by the field AcousticCategory. Refer to the AcousticCategory database table.
