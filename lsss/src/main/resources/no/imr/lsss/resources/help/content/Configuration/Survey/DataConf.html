Data files configuration

This section contains configuration of various directories and selection of data files.

When a new survey is created, the default locations for these directories are based on settings in [Application configuration - Directories] and the survey number and the name of the platform configured in [Survey configuration - Survey].

Directories

DataDir: Location of echosounder data.
The contents of this directory will appear in the file list table below.
KoronaDataDir: Location of processed echosounder data.
The toolbar button can be used to toggle between using data in DataDir and KoronaDataDir.
TrawlDataDir: Location of trawl data.
Used by the Trawl module.
CTDDataDir: Location of CTD data.
Used by the CTD module.
RefLogDataDir: Location of reference log data.
Used by overlays on the echogram and map.
FileDrawDataDir: Location of file draw data.
Used by an overlay on the echogram.
ReportsDir: Location of output from the database report generator.
WorkDir: Location of work files.
ExportDir: Location of output from exports.

Buttons

The button contains functions for sorting and grouping the rows in the file list table.

The button will reload the rows in the file list table.

The "Create idx..." button will become visible if some data files are missing index files. Pressing this button gives the option of creating new index files based on speed or position.

The "Create bot..." button will become visible if some data files are missing bot files and corresponding xyz files are available.

The "Calibration..." button contains functions for creating and editing a calibration file. This button becomes green if a calibration file exists and is used. If the calibration file contains errors, then an error message will appear below the row of buttons.

The "BEI / EK500..." button will become visible if there are EK500 data files in the DataDir directory. Press this button to edit settings and to convert work files. Read more in the BEI / EK500 appendix.

File list table

The files in this table can be sorted by file name or by time by using the button.

The columns in the file list table:

  • The first column shows the status of preprocessed data files. Hovering the mouse over the symbol will give a description in the tooltip of any errors or notices. Status symbols:
    No preprocessed file is available.
    The preprocessed file is found, but has not been checked yet.
    The preprocessed file is found, has been checked, and is OK.
    The preprocessed file is found, has been checked, and is OK, but a notice to the user is given.
    There is an error, and the file cannot be used. This will also disable the toolbar button for preprocessed files.
  • The second column shows the status of original data files. Hovering the mouse over the symbol will give a description in the tooltip of any errors or notices. Status symbols:
    The file has not been checked yet.
    The file has not been checked yet, but a notice to the user is given. The last file on the list is, for example, always given the notice symbol.
    The file is checked and everything is OK.
    The file is checked and is OK, but a notice is given to the user about, for example, corrections made to the file.
    There is an error, and the file cannot be used.
    If a file has not been checked, then one of the following symbols may be shown:
    The file has frequencies that are compatible with the current selection.
    The file has frequencies that are not compatible with the current selection.
  • The File column is the name of the file.
  • The Pings column gives the ping range for the data in the file.
  • The Duration column gives the duration, in format H:MM:SS, that the file represents.
  • The Dist column gives the start position and distance in parentheses, in nautical miles, that the file represents.
  • The ∑ sA column gives the sum of the interpreted area backscatter that is stored to the database.

Refer to the section on data correction for details on errors and warnings.
