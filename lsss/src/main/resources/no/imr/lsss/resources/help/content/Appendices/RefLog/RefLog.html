Reference log

The reference log files contain data about ship stations and other events that are logged on the ship.

The data directory is configured in [Survey configuration - Data files].

The data are shown as overlays on the echogram and on the map.

JSON files

This is a new file format that has replaced the ref csv files.

File names must be on the form *.json.

See an example file.

Ref csv files

This is a legacy file format, replaced by JSON files.

File names must be on the form ref*.csv.

A file consists of two header lines followed by data lines. The second header line contains descriptions of the data fields.

The second field in data line (Time) can have two formats:

  1. HH:mm:ss
  2. HHmmss.xx (The xx is ignored by LSSS)

See an example file.
