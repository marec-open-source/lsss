Name

SchoolMorphology - Object (number) used to group scatter info (e.g. a school)

Synopsis

struct SchoolMorphology {

  int   Object;

Description

Interpreted echo data from scattered fish is stored in the tables Scatter and ScatterData, and is grouped by the number Object (described below). Information about object morphology, e.g. a school of fish, is stored in the tables SchoolMorphology contains processing and support parameters, while SchoolData contains the integrated echo levels. Interpreted data is stored in the tables with a selectable horizontal resolution. The horizontal resolution is controlled by the DistanceInterval parameter in the Scatter table. Vertically, the data in Scatter and ScatterData is resolved into depth-channels; pelagic and bottom. The vertical resolution is controlled by the ChannelThickness parameter in the Scatter table.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - Unique survey identification code. See the Survey table.
  • Object - see Scatter table.
  • SchoolObjectType - Type of school object: see SchoolObjectType table.
  • ObservationDate [YYYYMMDD] - (UTC) Date of observation. Refer to the Observation table.
  • ObservationTime [hhmmssxx] - (UTC) Time of observation. Refer to the Observation table.
  • BoxDuration [1/100 s] - This parameter states the duration in hundredths of seconds for the current subinterval.
  • BoxThickness [m] - Uncorrected thickness: T. For corrected thickness: Tcorr = T - cb/2. c = sound speed, b= pulse length.
  • BoxLength [m] - Uncorrected length: L. For corrected length: Lcorr = (L - 2R tan(?/2)). R = school mean range.
  • MaxThickness [m] - Longest range of any vertical line from school bottom to top.
  • MaxLength [m] - Longest range of any horizontal line from school left to right.
  • Perimeter [m] - (P) X m between points. Corrected: Pcorr = P * C
  • Area [m] - Uncorrected area: A. Corrected area: Acorr = A(LcorrTcorr)/LT
  • Roughness [-] - (F) F = 2 * lg( P / 4 ) / lg( Area ). Corrected: FC = 2lg(PC/4)/lg(AC)
  • Circularity [-] - (C) Alternative to image compactness.
  • Rectangularity [-] - (R) R = LT / A
  • Elongation [-] - BoxLength/BoxHeight. Corrected: LC/TC
  • DistanceToBottom [m] - Distance where school is closest to bottom. Corrected: + c?/2
  • DistanceToSurface [m] - Distance where school is closest to the surface. Same as corrected.
  • BottomDepth [m] - Distance where school is closest to bottom. Same as corrected.
  • NmbAcousticCat [-] - Number of acoustic categories within school object. Should be = 1 for echogram library.
  • NmbHoles [-] - Number of holes in the school.
  • NmbKernels [-] - Number of kernels in the school.
