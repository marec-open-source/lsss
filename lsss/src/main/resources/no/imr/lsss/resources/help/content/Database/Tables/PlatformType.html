PlatformType

Name

PlatformType - Information about platform types and subtypes

Synopsis

struct PlatformType {
  short PlatformType;
  short PlatformSupType;
  char  PlatformTypeName[80];
  char  PlatformSubTypeName[80];
};

Description

This table contains the mapping from the name of the observation platform to nation code and platform code. The observation platform is often a ship.

Parameters

  • PlatformType - Code for type of observation platform. The standard list of observation platforms are: 0 = Unknown
    0 = Unknown
    1 = Land/Sea floor
    2 = Submersible
    3 = Ship (Default)
    4 = Buoy/Mooring
    5 = Balloon
    6 = Aircraft/Satellite/Rocket
    7 = Unassigned
    8 = 'Grid'
    9 = Other
  • PlatformSubtype - Code for subtype observation platform.
  • PlatformTypeName - Name of platform type, e.g. "ship".
  • PlatformSubTypeName - Name of platform sup-type, e.g. "research ship".

Note that currently always PlatformType = 3 and PlatformSubtype = 1, which means "Research vessel".
