CTD data

The CTD data can contain information from different sensors as a function of depth.

The data directory is configured in [Survey configuration - Data files].

The data are shown by the CTD module and by an overlay on the map.

Sta cnv files

File names must be on the form sta????.cnv.

The file is read in the following way:

  • The time, date, station, latitude, longitude, number of data columns, data column name are read from the header.
  • Data is expected to start after "*END*" mark and be columns corresponding to the data header.
