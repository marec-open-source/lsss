Copy remote survey data

This function copies data from the directories configured in [Survey configuration - Data files - Remote directories] to the directories configured in [Survey configuration - Data files]. Only files that are new or modified since last copying will be copied.

One possible way to organise the LSSS data directories on board the ships is to let LSSS work on local directories, configure the corresponding remote directories to where the sensors and instruments write their data files, and as needed copy the remote data files to the local directories. The benefit of this procedure is that it may be faster to load data from a local disk than from a network disk.

This function is started by selecting Copy remote survey data... from the file menu.
