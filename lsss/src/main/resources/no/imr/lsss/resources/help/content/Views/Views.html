Views

This chapter contains descriptions of the separate floatable views and the overlays to the echogram and map windows.

Input domains and domains affected by user actions

It is important to understand which domain is used in computation modules and which domain is affected by different user actions.

  • The computation modules that are shown in separate views (for example, frequency response module, threshold response module and TS distribution module) will only use the visible ping range of the active region(s) as the domain. Zooming in and out vertically will therefore not change the result of these computations, while zooming in and out horizontally will.
  • For the computation results that are overlaid on the echogram module, the domain is also limited to what is visible in the vertical direction. Examples here are the sA integration curve and the grid integration.
  • The sA assignments in the interpretation module will be stored as part of the regions. These assignments may therefore affect parts of the survey outside the visible ping range. Note however that when storing to the database, the ping range to be stored will be isolated from the rest of the survey by automatic insertion of vertical boundaries.
  • When storing to the database, only the grid cells completely inside the visible area will be stored. Hovering the mouse over the store button(s) will show which grid cells will be stored if all pings are loaded.
