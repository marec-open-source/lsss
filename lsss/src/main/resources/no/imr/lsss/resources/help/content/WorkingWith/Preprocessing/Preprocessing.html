Preprocessing

LSSS has a system for doing preprocessing. This system is referred to by the name KORONA. KORONA has a very modular design. It contains various computation modules, each performing a specific task. Several such modules can be chained together into a processing pipeline. The types of processing available include:

  • Bottom detection
  • Noise quantification and removal
  • Smoothing
  • Categorization
  • Region detection
  • Plankton inversion

The preprocessing system is a separate program and can be started from [Survey configuration - Preprocessing].

KORONA relay

KORONA relay is intended for batch processing. The files in the source directory are processed, and the result is written to the destination directory.

KORONA playbox

KORONA playbox allows for interactively exploring the processing. The results are displayed as the processing progresses.

Using preprocessed data in LSSS

When preprocessing is done, the results can be used in LSSS. The directory with the preprocessed files must be specified in [Survey configuration - Data files]. The preprocessed files are output as temporary files from KORONA relay, to not intervene with earlier preprocessed files open in LSSS. When entering the [Survey configuration - Data files], the user will be asked if the new temporary files should be copied for use in LSSS. If there are older preprocessed versions of the raw file, these will then be replaced. If the preprocessed data files are compatible with the selected original files, then the KORONA toolbar button becomes enabled. This button can then be used to toggle between the original data and the preprocessed data.

Results of the preprocessing are used in several ways. The processing that modifies the original data, such as smoothing and noise removal, is used directly in all computations in LSSS. In addition:

  • If categorization is done: The echogram can display categories instead of signal strength. This can be selected through the context menu of the colorbar.
  • If plankton inversion is done: The echogram can display plankton categories instead of signal strength. This can be selected through the context menu of the colorbar.
  • If region detection is done: The detected regions are displayed on the echogram. The detected regions can be converted to school regions for use in the interpretation through their context menu.

The categorization and plankton inversion results can further be used in the interpretation by setting up mappings between preprocessed categories and acoustic categories.

Preprocessing help system

More information can be found in the help system in KORONA, that can also be launched from the help menu or from [Survey configuration - Preprocessing].
