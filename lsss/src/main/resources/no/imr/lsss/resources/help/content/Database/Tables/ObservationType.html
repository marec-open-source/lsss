ObservationType

Name

ObservationType - Type of observation made

Synopsis

struct ObservationType {
  short ObservationType;
  char  ObservationTypeName[80];
};

Description

This table provides a mapping between the observation type code and the observation type name. Note that there is a maximum length of the name.

Parameters

  • ObservationType - Unique identifier code for defined event types. Currently, the following observation types are defined:
    0 = Unspecified
    1000 = NAVIGATION = Navigation Data Input
    2000 = ACOUSTIC_START = Start of data file containing acoustic data
    2010 = ACOUSTIC_STOP = End of data file containing acoustic data.
    3000 = SCATTER = Scattered Fish Data
    4000 = SCHOOL = Scattered Fish Data interpreted as a school of fish
    5000 = OCEANOGRAPHY = Oceanography Data Input
    6000 = BIOLOGY = Biology Data Input
    7000 = METEOROLOGY = Meteorology Data Input
    8000 = SCATTER_OBJECT_DUMMY
    9000 = SCATTER_OBJECT_SCHOOL = Scatter object of type school
    10000 = SCATTER_OBJECT_PELAGIC = Scatter object of type pelagic echogram
    A Scattered Fish Data event line is added to the Observation table for each interpreted grid column where date, time, log, latitude, longitude and bottom depth all refer to the start of the grid column. Note that the content may be expanded when LSSS is expanded with a new plugin subsystem (see manual of the plugin subsystem).
  • ObservationTypeName - Free text to name and/or describe the event. Note the maximum length.
