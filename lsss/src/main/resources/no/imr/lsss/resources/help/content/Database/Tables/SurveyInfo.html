SurveyInfo

Name

SurveyInfo - Information/metadata about a survey

Synopsis

struct SurveyInfo {
  short Nation;
  short Platform;
  int   Survey;
  char  InfoKey[40];
  int   InfoIndex;
  char  InfoValue[30000];
};

Description

This table is a key-value store for metadata related to a survey.

This table is, for example, used for storing ICES acoustic metadata used in the database report with Print format 25.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - Unique survey identification code. Refer to the Survey database table.
  • InfoKey - The key for this entry.
  • InfoIndex - If the metadata is too long to fit into one entry, then it is split into several entries with an increasing number of InfoKey.
  • InfoValue - The value for this entry.
