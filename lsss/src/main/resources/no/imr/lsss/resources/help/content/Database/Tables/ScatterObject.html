ScatterObject

Name

ScatterObject - Object (number) used to group scatter info (e.g. a school)

Synopsis

struct ScatterObject {
  short Nation;
  short Platform;
  int   Survey;
  int   Object;
  int   ObservationDate;
  int   ObservationTime;
  short ObservationType;
  int   Duration;
};

Description

Interpreted echo data from scattered fish is stored in the tables Scatter and ScatterData, and is grouped by the number Object (described below). Information about object morphology, e.g. a school of fish, is stored in the tables SchoolMorphology contains processing and support parameters, while SchoolData contains the integrated echo levels. Interpreted data is stored in the tables with a selectable horizontal resolution. The horizontal resolution is controlled by the DistanceInterval parameter in the Scatter table. Vertically, the data in Scatter and ScatterData is resolved into depth-channels; pelagic and bottom. The vertical resolution is controlled by the ChannelThickness parameter in the Scatter table.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - Unique survey identification code. See the Survey table.
  • Object - see Scatter table.
  • ObservationDate - [YYYYMMDD] (UTC) Date of observation. Refer to the Observation table.
  • ObservationTime - [hhmmssxx] (UTC) Time of observation. Refer to the Observation table.
  • ObservationType - Code for which type of observation made. Refer to the ObservationType database table.
  • Duration - [1/100 s] This parameter states the duration in hundredths of seconds (1/100) for the scatter-object.
