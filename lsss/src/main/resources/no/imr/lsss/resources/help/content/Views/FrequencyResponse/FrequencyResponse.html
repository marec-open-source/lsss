Frequency response

This view shows the frequency response curve with standard error curves for the currently selected region(s).

The normalized frequency response, r, for frequency f with fN as normalization frequency is defined as

r(f) = s̅v(f) / s̅v(fN)

where

s̅v(f) = (1 / Nf) ∑ sv(f)

The summation is over all samples in the selected regions (Nf samples). If a sample has a sv value below the lower threshold or above the upper threshold (if the upper threshold is active), then sv = 0 is used for that sample.

The normalization frequency fN can be configured in [Survey configuration - Miscellaneous].

The standard error for frequency f of the frequency response function is estimated as

SE( r(f) ) = SE(f) / s̅v(fN)

where the standard error of the mean for frequency f is estimated as

SE(f) = σ(f) / sqrt(Nf)

where sigma is the estimated standard deviation of the sample values.

Settings

  • X-axis: The type of x-axis. Possible choices:
    • IDENTITY: Linear mapping.
    • SQRT: Square root mapping.
    • CBRT: Cube root mapping.
    • LOG: Logarithmic mapping.
  • Y-axis: The type of y-axis. Possible choices:
    • DYNAMIC: The axis is linear, and dynamically expands depending on the range of the axis values.
    • FIXED: The axis is linear, and the range is fixed between 0 and 6.
    • SQRT: Dynamical square root mapping.
    • CBRT: Dynamical cube root mapping.
    • LOG: Dynamical logarithmic mapping.
  • Plot std. err.: If checked, standard error curves will be plotted.
  • Show legends: Show legends for the selected KORONA categories.
  • Plot interpretation function: Plot the frequency response function defined in the Interpretation module.
  • Plot KORONA categories: Plot the frequency responses for the KORONA categories defined in the main preprocessing setup.
  • KORONA categories: Which KORONA categories to plot.
