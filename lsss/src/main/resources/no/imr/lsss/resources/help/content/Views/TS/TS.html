TS distribution

The purpose of the TS module is to visualize the target strength distribution of the detected single targets in the active regions. The distribution for the currently active frequency is shown with a thick piecewise histogram-like curve as shown below. To avoid a cluttered plot, the distributions for the other frequencies are shown with piecewise linear curves.

The TS locations overlay can display the positions of the detected targets in the echogram.

The TS positions module can display the angles of the detected targets.

The BB TS(f) module can detect targets for broadband data and display frequency spectra.

Settings

Target detector settings

See the TS detection module in KORONA for further description on the target detector settings.

  • Detector type: The target detector type. Choices:
    • SED: Detect targets using the SED algorithm.
    • Peak: Detect targets using the Peak algorithm.
    • KORONA: Use targets already detected by the TS detection module
  • Min TS: Minimum corrected TS value to be detected [dB].
  • Pulse length determination level: Pulse length determination level [dB].
  • Min echo length: Minimum echo length (relative to pulse length). NB: may be << 1 for pulse compressed data!
  • Max echo length: Maximum echo length (relative to pulse length). NB: may be << 1 for pulse compressed data!
  • Max gain compensation: Maximum (one way) gain compensation [dB].
  • Do phase deviation check: Check this if phase deviation check should be performed.
  • Max phase deviation: Max phase deviation [phase steps].
  • Max depth: Maximal depth of targets [m]. Optional, may be left blank.

Display settings

  • Delta TS: The histogram bin size.
  • Min TS: The minimum value shown in the TS plot, i.e. the lower limit of the x-axis.
  • Max TS: The maximum value shown in the TS plot, i.e. the upper limit of the x-axis.

Export
