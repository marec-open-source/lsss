SchoolData

Name

SchoolData - Multi-frequency acoustic measurements on a school object

Synopsis

struct SchoolData {
  short  Nation;
  short  Platform;
  int    Survey;
  int    Object;
  short  SchoolObjectType;
  int    Frequency;
  int    Transceiver;
  int    FrequencyRef;
  int    TransceiverRef;
  float  SA;
  float  SL;
  float  RF;
  float  rf_sdev;
  float  sv_mean;
  float  sv_sdev;
  float  Skewness;
};

Description

This table provides a mapping between the observation type code and the observation type name. Note that there is a maximum length of the name and the description.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - Unique survey identification code. See the Survey table.
  • Object - see Scatter table.
  • SchoolObjectType
  • Frequency [Hz] - see Scatter table.
  • Transceiver [-] - see Scatter table.
  • FrequencyRef [Hz] - Reference frequency, usually 38 kHz.
  • TransceiverRef [-] - Transceiver number of reference frequency.
  • sA // Total sA (or total sv?)
  • sL or object_length // Length [m] (so that abundance can be calculated)
  • rf (sA/sA_ref) // Corrected value is the same.
  • rf_sdev // Corrected value is the same.
  • sv_mean // Corrected: sv_mean * A / AC * 10**(dSvC/10)
  • sv_sdev // [ (sv_mean - sv_i) / (n-1) ] ** 0.5
  • Skewness // Skewness should be OK for same measurement frequency.
