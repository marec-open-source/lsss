PlatformCodes

Name

PlatformCodes - Platform codes in several code systems

Synopsis

struct PlatformCodes {
  short Nation;
  short Platform;
  char  PlatformCodeSysName[80];
  int   FirstValidDate;
  int   LastValidDate;
  char  PlatformCode[80];
};

Description

This table contains the mapping from the unique platform code used by the database internally to other code systems. Other code systems may be e.g. "Callsign", which for RV "G.O.Sars" (1970-2002) were LLZG, or ICES ship codes are "ICESnnsss", where nn is nation and sss is shipcode, which for the same RV "G.O.Sars" were "ICES58015" (Norway = 58, "G.O.Sars" = 15).

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Platform identification code. Refer to the Platform database table.
  • PlatformCodeSysName - Name of code system.
  • FirstValidDate - [YYYYMMDD] First date the observation platform was operational.
  • LastValidDate - [YYYYMMDD] Last date the observation platform was operational.
  • PlatformCode - Code of platform in this code system.
