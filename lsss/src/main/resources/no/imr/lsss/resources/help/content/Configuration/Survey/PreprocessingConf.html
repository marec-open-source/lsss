Preprocessing configuration

This section contains data processing setups for use on the fly while loading data in LSSS, and for preprocessing using KORONA.

On the fly

Some of the KORONA modules can be used on the fly while loading data. This kind of processing can be done without writing the processed data to files in a directory. If on the fly processing is configured, a notice is shown in the status bar.

  • Use on the fly processing: Select if on the fly processing should be used.
  • On the fly processing of DataDir: The processing setup to use for on the fly processing.
  • Apply even if already processed: Select if on the fly processing should be applied even if the data is already processed.

KORONA relay

The preprocessing program, KORONA relay, can be started from this panel. Several preprocessing setups can be defined by clicking the "Add preprocessing setup" button.

  • Comment: An optional comment about this processing setup.
  • Config file settings: A file containing the paths to config files used by processing. See the KORONA help system, section "Config File Settings" for more information.
  • Source directory: Location of files to be processed.
  • Destination directory: Location of the processed files.

These setups are also used by the KORONA experimentation module.
