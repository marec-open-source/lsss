Trawl

The Trawl module displays catch data from trawl stations.

The module contains two main parts, a toolbar and a graphic display.

The toolbar contains items for selecting a trawl data file and for navigating between the different stations within the file.

File formats

Two trawl file formats are supported.

SPD

This is an internal IMR format with file extension *.spd. Format description can be found in the following reference:

Håndbok for prøvetaking av fisk og krepsdyr ver. 3.15 by Hildegunn Mjanger, John Alvsvåg, Knut Hestenes, Bjørn Vidar Svendsen and Thomas de Lange Wenneck

BIOTIC

This is an internal IMR format with file extension *.xml. The XML schema is available at: https://www.imr.no/formats/nmdbiotic/v3/nmdbioticv3.xsd.
