Database configuration

Before LSSS can be used for setting up a new survey, the database connection must be configured. This is done in the following steps:

  1. Select one of the supplied database types.
  2. Configure the relevant parameters for the selected database.
  3. Press the "Connect" button to connect to an existing database or press the "Initialize" button to initialize a database. Note that initializing a database will delete all existing data.

Most database types require access to an account on an external database server. This is the case for PostgreSQL. It may also be required, depending on account privileges, that the database is already created on the database server.

The databases HSQLDB and Java DB do not require any additional installation. The content of HSQLDB is stored in files (text or binary), and kept in memory while in use. This means that it is suitable only for relatively small databases.
Java DB stores data to binary files. It has no limitations on the size of the database.

Generic database connection

This option enables the use of any database with a JDBC connection and a Hibernate SQL dialect implementation. No guarantees are given about the interoperability between any particular such database and LSSS.

To use this option first do this:

  1. Download the jar file containing the JDBC driver from the database vendor.
  2. Place the jar file in the directory [LSSS installation]/lib/jar.
  3. Restart LSSS.

Then configure these parameters:

  • JDBC driver: The fully qualified class name of the JDBC driver.
  • SQL dialect: The fully qualified class name of the Hibernate SQL dialect.
  • Connection URL: The URL for connecting.
  • Username: The username (if required).
  • Password: The password (if required).
  • Save password: If selected, then the password is saved encrypted in the configuration file.

Example for the H2 Database Engine:

  • JDBC driver: org.h2.Driver
  • SQL dialect: org.hibernate.dialect.H2Dialect
  • Connection URL: jdbc:h2:file:C:/data/test
