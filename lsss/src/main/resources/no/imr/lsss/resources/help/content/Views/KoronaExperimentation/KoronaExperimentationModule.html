KORONA experimentation

This module is intended for experimenting with KORONA preprocessing. The selected regions are preprocessed using one of the setups defined in [Survey configuration - Preprocessing] and the result is displayed in a secondary LSSS frame.

The ping range processed is the span of the selected regions extended according to the parameter Ping padding, but limited to the currently visible ping range.

The module view, shown the figure below, has these inputs:

  • Preprocessing setup #n: The selected setup in [Survey configuration - Preprocessing].
  • Process: Starts processing using the currently selected setup.
  • Edit: Shows the module editor for the currently selected setup.

Settings

  • Preprocessing setup: The selected setup in [Survey configuration - Preprocessing]. The same setting is also shown in the dropdown in the module view.
  • Ping padding: The number of extra pings added on each side of the selected range.
  • Process: Button for starting the processing.
  • Server port: Port for the scripting server in the destination LSSS. Leave blank to disable.
