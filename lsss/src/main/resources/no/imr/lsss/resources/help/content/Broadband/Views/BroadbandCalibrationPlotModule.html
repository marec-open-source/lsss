BB calibration plot

This view plots the frequency-dependent broadband calibration specified in the file calibration.xml and the default correction formulae.

Description

The plot is updated when the mouse is moved and shows the calibration for the corresponding ping. The figure below shows an example plot where:

  • ╱ Gray line: The default formulae
  • ╱ Blue line: The broadband calibration
  • ╱ Red line: Constant extrapolation of the broadband calibration
