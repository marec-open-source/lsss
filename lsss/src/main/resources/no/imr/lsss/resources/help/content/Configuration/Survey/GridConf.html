Grid configuration

This section defines the grids used when storing to the database. Storing and deleting can be done from the interpretation window, and the grids can be displayed as an echogram overlay.

Database grid

  • Unit of horizontal grid: The unit used for the horizontal grid settings below. Possible choices are pings, nmi and seconds. This unit determines how sV is integrated over several pings and thus affects sA and sL.
  • Horizontal grid size: This is the horizontal size of the pelagic and bottom grids.
  • Minimum horizontal grid size: Grid columns that are partly excluded will automatically be divided into shorter grid columns, which will only be used if they have at least this size.
  • School horizontal grid size: The horizontal size for pelagic and bottom school grids.
  • Echogram vertical grid size - pelagic: The vertical size in meter of pelagic grid cells.
  • Echogram vertical grid size - bottom: The vertical size in meter of bottom grid cells.
  • School vertical grid size - pelagic: The vertical size in meter of pelagic school grid cells.
  • School vertical grid size - bottom: The vertical size in meter of bottom school grid cells.
  • Vertical extent - bottom: The vertical extent in meter of the bottom grids. The bottom grids go from z = 0 up to minus this value.

Display settings

  • Echogram horizontal display - preferred size: The preferred segment sizes when interpreting a survey. Multiple sizes can be specified as a comma separated list. The toolbar and the interpretation window have buttons for setting the segment sizes specified here.
  • Automatic DETAIL mode: Automatically enter DETAIL data loading mode when clicking a preferred size button.
