SchoolObjectType

Name

SchoolObjectType - Type of school object

Synopsis

struct SchoolObjectType {
  short SchoolObjectType;
  char  SchoolObjectTypeName[40];
  char  SchoolObjectTypeDescription[80];
};

Description

This table provides a mapping between the observation type code and the observation type name. Note that there is a maximum length of the name and the description.

Parameters

  • ObservationType - Unique identifier code for defined event types. Currently, the following choices are suggested for type and type name:
    10 = School-Vertical-Alongship, uncorrected // E.g. from echo sounder or slice from sonar.
    11 = School-Vertical-Alongship, corrected // ---------- ? ---------- ? -------- ? ------
    40 = School-Kernel, uncorrected
    41 = School-Kernel, corrected // Corrected could be ?smoothed? gravitation centre
    100 = Echogram-slice, uncorrected
  • SchoolObjectTypeName - Free text to name and/or describe the event. Note the maximum length.
