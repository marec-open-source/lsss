Working with tracks

This section lists some functionality for working with tracks in LSSS.

Tracks are generated by the KORONA tracking module.

Visualization

Tracks can be visualized:

  • By the tracks echogram overlay
  • Positions of selected tracks are shown by the TS positions view

Selection

Tracks can be selected by:

  • Drawing a selection rectangle in the echogram
  • Clicking on individual tracks in the echogram
  • By using the labels assigned to tracks

Labels

In LSSS tracks can be assigned custom labels. The labels can optionally be displayed by the tracks echogram overlay.

Editing

Tracks can be edited by:

  • Merging tracks (does not add new positions)
  • Splitting a track into two separate tracks
  • Deleting tracks

The editing functionality can be accessed via the context menu of the tracks echogram overlay.

Visual editing

Tracks can be visually edited using TSU only and not angles. TSU can be visualized in the echogram by selecting TSU as the continuous variable in the 'Advanced' dialog accessible via the context menu of the Colorbar.

Visually edited parts of tracks are treated differently:

  • Visually distinct display by the tracks echogram overlay
  • Angles are not shown by the TS positions view
  • Angles are not exported

The visual editing functionality can be accessed via the context menu of the tracks echogram overlay.

Joining tracks

The selected tracks will be joined by adding points between them, and merged to one track. The added points are located at TSU peaks.

Extending tracks

The extension is done to the left or to the right depending on which end of the track the mouse is closest to. The track is extended as long as the next TSU peak is above the current lower TSU threshold.

Semi-automatic drawing

When the semi-automatic drawing mode is active and the mouse is over a track, then that track can be edited by dragging the mouse with the left button down.

Points are added to the track at the TSU peak closest to the mouse position.

Keyboard functions in this mode:

  • Esc: Cancel current editing
  • Space: Toggle draw / delete
  • D: Delete selected tracks
  • E: Extend current track (left or right) depending on mouse position
  • J: Join selected tracks
  • M: Merge selected tracks
  • R: Redo track edit
  • S: Split current track at mouse position
  • U: Undo track edit

Export

Tracks can be exported:

  • Narrowband: Tracks export
  • Broadband: BB TS(f) tracks export

Angles are not exported for visually edited parts of tracks.
