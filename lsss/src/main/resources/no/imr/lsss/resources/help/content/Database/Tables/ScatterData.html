ScatterData

Name

ScatterData - Integrated echo-level in depth-channels

Synopsis

struct ScatterData {
  short Nation;
  short Platform;
  int   Survey;
  int   Object;
  int   ObservationDate;
  int   ObservationTime;
  int   Frequency;
  short Transceiver;
  short ScatterType;
  int   ChannelNumber;
  int   AcousticCategory;
  float SA;
};

Description

Interpreted echo data from scattered fish is stored in the tables Scatter and ScatterData. Scatter contains processing and support parameters, while ScatterData contains the integrated echo levels. Interpreted data is stored in the tables with a selectable horizontal resolution. The horizontal resolution is controlled by the DistanceInterval parameter in the Scatter table. Vertically, the data in Scatter and ScatterData is resolved into depth-channels; pelagic and bottom. The vertical resolution is controlled by the ChannelThickness parameter in the Scatter table.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - Unique survey identification code. See the Survey table.
  • Object - see Scatter table.
  • ObservationDate - [YYYYMMDD] (UTC) Date of observation. Refer to the Observation table.
  • ObservationTime - [hhmmssxx] (UTC) Time of observation. Refer to the Observation table.
  • Frequency - [Hz] Echosounder operating frequency in Hz. Refer to the Scatter table.
  • Transceiver - Echosounder transceiver channel number. Refer to the Scatter table.
  • ScatterType - Type of scatter data. See the ScatterType table.
  • ChannelNumber - The pelagic channels are parallel to the sea surface, and the bottom channels are parallel to the bottom. Their thickness is defined by the ChannelThickness parameter in the Scatter table. See ScatterType table for definitions of the channel types. ChannelNumber increase with increasing distance from the reference, i.e. surface-related depth-channels increase with increasing depth below surface, and bottom related channels increase with increasing distance above bottom.
  • AcousticCategory - Code of acoustic category code. See the AcousticCategory table. Note that category code 0 implies that the sA parameter contains raw non-interpreted data; bubble correction included, assignment factors onto acoustic categories excluded.
  • SA - This parameter (sA, area backscattering coefficient, Nautical Area Scattering Coefficient - NASC) contains the integrated echo level for a particular subinterval/channel/active-acoustic-category triplet. The parameter has dimension square meter per square nautical mile. The value is allocated to one acoustic category.

Data storage

A number of lines are added to the ScatterData table. All permutations of subinterval, channel or active acoustic category are stored as separate lines. Hence, U x C x A lines are added every base interval:

  • U is the number of subintervals.
  • C is the number of visible channels within the pelagic and bottom echogram. Note that pelagic channel 0 and bottom channel 0 are special sum channels.
  • A is the number of active acoustic categories including acoustic category 0. Note that acoustic category 0 is a special identifier for raw non-interpreted echo level. The number of lines added can be quite large with unfavorable settings. Therefore, the Scrutinize program only stores lines containing a nonzero SA value. Hence, no lines are stored for pelagic channels that are located below the bottom echogram and for active categories that are assigned a distribution factor of zero in the Interpretation window. Two examples will illustrate the storage mechanisms further. Typical situation: Assuming a horizontal resolution of 1.0 nautical mile (U = 5), 17 visible channels (C = 17) and 3 active acoustic categories (A = 3+1 = 4) a maximum of 5x17x4 = 340 lines are added every base interval. Typically, the number of lines actually stored will be somewhat lower due to the fact that some pelagic channels are below the bottom and that some acoustic categories are given an assignment factor of zero.
