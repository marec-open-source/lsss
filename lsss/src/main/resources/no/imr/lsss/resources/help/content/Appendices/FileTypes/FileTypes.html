File types

Below is an overview of file types used by LSSS:

Data input files

  • raw: The echosounder main input files containing sample data. Preprocessed files have the same file extension, and may contain additional data not available in standard raw files.
  • idx: Index files for the raw sample files.
  • bot: Files containing the detected bottom.
  • ctd:
  • draw:
  • reflog:
  • spd: Trawl data files.

Data output files

  • work: Work files containing, among other things, region definitions and assignment to acoustic categories.
  • snap: Copies of work files written by LSSS prior to version 2.10.0.
  • lsss: Contains all the settings specified in [Configuration - Survey configuration]. The location of this file is selected in the last step in the sequence of setting up a new survey.
  • log: Contains system messages and debug information.

Default configuration files

Two configuration files containing the default settings may exist. They are stored in the directory .ApplicationData/lsss/config in the user home directory.

  • application.xml: The default application settings. This is stored every time a survey is stored and when actively choosing to store the settings from the application configuration main tab.
  • survey.xml: The default survey settings. This is saved only when actively choosing to do so from the survey configuration main tab.
