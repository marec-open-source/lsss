Keyboard shortcuts

This is a summary of keyboard shortcuts in LSSS. Some keystrokes can be seen in menus and tooltips.

Main window

Keyboard shortcuts for the main window.

Keystroke Description
Ctrl + E Edit the current survey configuration
Ctrl + F Freeze / unfreeze the currently selected ping and geographical position as shown by, e.g., overlay on the echogram and overlay on the map
Ctrl + N Create a new survey
Ctrl + O Open a previously saved survey configuration
Ctrl + S Save the current survey configuration
Ctrl + T Toggle the display of the tooltip in the echogram and the map
Ctrl + Z
Ctrl + Shift + Z		 Undo / redo the last school region edit
Ctrl + Left
Ctrl + Right		 Step to the previous / next echogram segment
Ctrl + Alt + Left
Ctrl + Alt + Right		 Go to the previous / next echogram resolution (and location)
F1 Show help
F2 Toggle showing masking of stored areas
F3 Toggle showing categorization echogram for preprocessed data
F4 Toggle showing plankton echogram for preprocessed data
F5 Toggle conditional masking
F12 Toggle showing only echogram

Shift + Home		 Zoom out maximally in both directions / only vertically
+
-		 For frequency-dependent deletion: Change the size of the paintbrush

Ctrl + Shift + Right

Ctrl + Shift + Down		 Pan 0.1 of the echogram size

Page Up
Page Down		 Select the next / previous frequency
Ctrl + Alt + Left

Scroll wheel

1 Locking / unlocking when editing regions
Similar to pressing / releasing the left mouse button
