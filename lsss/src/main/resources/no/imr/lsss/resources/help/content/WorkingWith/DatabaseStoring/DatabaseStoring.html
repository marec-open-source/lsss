Database storing

Storing to the database means integrating the raw data to coarser grids that are stored to the Scatter and ScatterData tables.

Storing and deleting can be done from the interpretation window.

Bottom grids are not stored in pelagic mode. Bottom grids always refer to the coordinated bottom.

Storing settings

These are the settings that affect the grids stored to the database.

Survey level settings

These settings are common for the survey, and are saved to the .lsss survey file.

  • Grid unit and sizes
  • Whether the raw data species should be stored.

Horizontally varying settings

These settings can vary horizontally, and are saved in the work files.

  • Which data directory to use (DataDir or KoronaDataDir)
  • Pelagic or bottom mode
  • Interpretation quality
  • Which frequencies to store

Some of these settings can be visualized in the echogram plot.

Storing states

Horizontal distances in the echogram can be in three different states depending on whether that distance is, or should be, stored to the database.

Not stored to the database, and storing settings are not defined

This is the starting state for a new survey before anything has been stored to the database. There is no special indication of this state in the echogram.

Possible actions in this state:

  • Store: Store to the database using the currently selected settings. These settings will be saved in the work files for this distance.

Stored to the database

This state is entered by using the store button in the interpretation window. The echogram indicates this state with green sA numbers and a semi-transparent green overlay on the stored frequencies.

The echogram becomes read-only in these areas. Regions that are only partly stored also become read-only.

Possible actions in this state:

  • Delete: Delete from the database, but keep the storing settings.

Not stored to the database, but storing settings are defined

This state is entered by using the delete button in the interpretation window. The echogram indicates this state with a striped green overlay.

The echogram is not read-only in this state. The storing settings can be changed from the interpretation window.

Possible actions in this state:

  • Store: The striped area will be stored to the database using the defined storing settings.
  • Delete: The storing settings will be deleted.
