Export

Many of the LSSS modules can export data. By selecting File->Export to files..., a dialog with all available exports pops up, and exporters can be selected/deselected and configured individually.

Common for all export types:

  • Area exported:
    • The exported area is limited to the horizontally zoomed range.
    • Vertical zooming does not limit the exported area.
      (Except for exporting echosounder data with option 'Zoomed vertically' selected.)
    • The export is limited to selected regions.
      (Except for exporting echosounder data.)
  • All pings are used, even if browse mode is currently active.
  • The exported file names are of the form
    <Optional prefix><Export type>_T<Start time>-<Stop time>[_nn].<Suffix>
    where start time and stop time are on the form YYYYMMDD_HHMMSSXX, and nn is a counter added to avoid overwriting existing files.
  • If the export is done on preprocessed data, then the module setup is also saved.
  • The format and content of the exported files may change in future versions of LSSS.

Broadband data

See the separate page on broadband export.

Echogram plot

Exports the functions selected by the Echogram plot module.

Changes:

  • LSSS 2.16.0: If the parameter Plot all channels is selected, then the export will contain values for all channels for channel-dependent variables. Prior to 2.16.0 only the current channel was exported.

Echosounder data

Exports the horizontally visible echosounder data to raw files. Selected regions do not limit what is exported.

Options:

  • Zoomed vertically: When selected then
    • Only the vertical extent visible in the pelagic echogram is exported.
    • Only RAW0 datagrams are exported.

School parameters

Exports school parameters for the selected schools.

Changes:

  • LSSS 2.8.0: Renamed "acousticCategories" to "scrutiny".

Sv

Exports sample values in the selected regions.

Tracks

Exports tracks detected by the KORONA tracking module. Only tracks completely contained in the selected regions are exported.

TS

Exports TS targets detected by TS module in the selected regions.

Changes:

  • LSSS 1.9.3: Renamed column "sv" to "sV_of_peak".
