SchoolDetect

Name

SchoolDetect - Multi-frequency acoustic measurements on a school object

Synopsis

struct SchoolDetect {   //How calculations were done to process data
  short Nation;
  short Platform;
  int   Survey;
  int   Object;
  float DetectionThreshold;
  float DetectionThresholdHole;
  float MinSizeHole;
  float SmoothVertical;
  float SmoothHorizontal;
  char  DetectionSettings[1024];
  short ManuallyCorrected;
};

Description

This table provides a mapping between the observation type code and the observation type name. Note that there is a maximum length of the name and the description.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - Unique survey identification code. See the Survey table.
  • Object - see Scatter table.
  • DetectionThreshold [dB] - Detection threshold for the synthetic channel where the school extent was detected.
  • DetectionThresholdHole [dB] - Detection threshold for hole of school.
  • MinSizeHole [m] - Minimum length/height of hole to be accepted.
  • SmoothVertical [m] - Vertical smoothing diameter.
  • SmoothHorizontal [m] - Horizontal smoothing diameter.
  • DetectionSettings - Detection settings used by preprocessor (KORONA).
  • ManuallyCorrected - False if automatically detected school, true else.
