Plugin configuration

This section configures which of the available plugins should be enabled. Note that enabling or disabling a plugin only takes effect after restarting LSSS.

Most plugins, such as Deep Vision and PROFOS, are disabled by default on a new installation, so that their modules, overlays and configuration sections are not shown unless they are needed. The LSSS server plugin is enabled by default. Plugins that have been installed manually in the plugin directory are also enabled by default.

Plugins can extend the functionality of LSSS in a number of ways, including:

  • Adding new modules.
  • Adding new overlays to the echogram or the map.
  • Adding new exports.
  • Adding new sections to the configuration.
  • Adding new tables to the database.
