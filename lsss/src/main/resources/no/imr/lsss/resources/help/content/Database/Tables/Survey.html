Survey

Name

Survey - Survey data

Synopsis

struct Survey {
  short Nation;
  short Platform;
  int   Survey;
  char  SurveyTitle[80];
  int   StartDate;
  int   StartTime;
  int   StopDate;
  int   StopTime;
  char  SurveyDescription[200];
  float BoundaryNorth;
  float BoundarySouth;
  float BoundaryWest;
  float BoundaryEast;
};

Description

This table contains information describing the individual surveys. The survey information may be entered at the beginning of each survey, or alternatively, the complete survey schedule is entered at the beginning of the year with minor updates being performed throughout the year.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • Survey - A survey code is assigned to each survey. This code must be unique within each Nation/Platform pair. There may be several ships and nations participating on a survey, and the survey code provides a mechanism for combining observation data from all participating ships.
  • SurveyTitle - Short title to name the survey. Note that maximum 80 characters may be used.
  • StartDate - [YYYYMMDD] First day of the current survey. Dates must refer to Universal Time Coordinated (previously denoted Greenwich Mean Time). Dates are coded using eight decimal digits, for example 20040823.
  • StartTime - [hhmmssxx] Start time of the current survey. Date and time refer to Universal Time Coordinated (previously denoted Greenwich Mean Time). Time is coded using eight decimal digits, for example 17235489 (17 hours, 23 minutes, 54 seconds, 89 hundredths of a second).
  • StopDate - [YYYYMMDD] Last day of current survey.
  • StopTime - [hhmmssxx] End time of current survey.
  • SurveyDescription - 200 characters space is available for a short survey description and other comments.
  • BoundaryNorth - Geographical latitude and longitude limiting the area surveyed by this platform on the current survey. Latitude (positive north) and longitude (positive east) are expressed as floating point numbers in degrees.
  • BoundarySouth - See BoundaryNorth.
  • BoundaryWest - See BoundaryNorth.
  • BoundaryEast - See BoundaryNorth.
