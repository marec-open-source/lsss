AreaOfAcousticCategory

Name

AreaOfAcousticCategory - Coupling between sea area and acoustic category

Synopsis

struct AreaOfAcousticCategory {
  short Nation;
  short Platform;
  int   AcousticCategory;
  int   Area;
};

Description

This table contains coupling between the AcousticCategory and the Area database tables. The coupling is done to reduce the list of acoustic categories to a more convenient size when selected to be used in the scrutinizing session.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique identification code for observation platform. Note that Platform = 0 means "national-wide" or "institute-wide" entry of the database table. Refer to the Platform database table.
  • AcousticCategory - Acoustic category, i.e. "acoustic species". Refer to the AcousticCategory.
  • Area - Unique identification code for area. Refer to the Area database table.
