Report generator

Description

The report generator provides means to output data from the database. The user selects a survey and at least one report from a set of pre-defined report formats. The reports are stored in the ReportsDir directory, which is set from [Survey configuration - Data files], and also shown in the report generator window. The reports are generated for all frequencies. For some pre-defined report formats, only some species are printed. The number of species printed in those special reports is set from the report generator window. The naming of the print-files is similar to the report generator of Bergen Echo Integrator, BEI, i.e. the report format 5 is the same as ListUser05 in BEI. Some reports were not much used during the latest years of BEI, and those are not currently included in LSSS.

Naming of print files

The print files are named: ListType_LStart-stop_Postfix

  • Type gives the format name but also the frequency and transceiver if there is only one of those, e.g. "User02_F038000_T02". If the file contains all frequencies and transceivers, frequency and transceiver is not given in the file name.
  • Start-stop is the start and stop distance of the print-file. Note that Start is at or after the requested start-distance of the reporting, and that the distance is independent of frequency. In other words, if the requested start-distance is 1000 nmi, and there is stored data from 1000 nmi at 38 kHz and from 1200 nmi at 70 kHz, both the name of the 38 kHz file and the 70 kHz file be named "....._L1000.0-....". The similar is true for the stop distance.
  • _Postfix gives the name of the acoustic category (="acoustic species") in short form (5 letters) if the file contains only one.

Example of file names are: ListUserFile05__F038000_T2_L3197.0-3234.0_HERRI and ListUserFile20__L3197.0-3234.0

Intended use of report formats

  • Compact format: Paper printouts. Each species occupy one column.
  • Print format 2: Similar to "Compact" format, but with comments, empty lines excluded to make the files more suitable for automatic use, and with 3 decimals.
  • Print format 3: Similar to "Print format 02", but comma separated columns suited for use in e.g. MS Excel.
  • Print format 4: Input fitted for e.g. MS Excel with all info on each line. Max number of pelagic depth channels. Each file contain one species measured at one acoustic frequency.
  • Print format 5: General output suitable as input to a long range of programs, e.g. SAS. Each file contains one species measured at one acoustic frequency.
    Note that only the selected number of acoustic categories on the Species sub-dialog in the SurveyConfiguration dialog will be printed.
  • Print format 7: PGNAPES format (1)
  • Print format 8: PGNAPES format (2)
  • Print format 9: Input fitted for e.g. MS Excel with all info on each line. High number of pelagic and bottom depth channels. Each file contains one species measured at one acoustic frequency.
  • Print format 11: Each file contains one species measured at one acoustic frequency.
  • Print format 16: Each file contains all selected species at one frequency.

The following print formats (20-40) can only be printed in native resolution, i.e. in the resolution as stored in the database:

  • Print format 20: XML file suitable for general abundance estimation. Each file contains all selected species and is sorted by increasing time and increasing frequency.
  • Print format 21: Report format intended for estimating the backscatter at frequency "f" relative to "38 kHz" (i.e. the "relative frequency response). Print format 21 has fixed columns. The file contains the relative frequency response for the first species selected.
  • Print format 22: Report format intended for estimating the backscatter at frequency "f" relative to "38 kHz" (i.e. the "relative frequency response). Print format 22 is comma separated unlike print format 21 that has fixed columns. The file contains the relative frequency response for the first species selected.
  • Print format 23: Report format intended for estimating the backscatter at frequency "f" relative to "38 kHz" (i.e. the "relative frequency response). Print format 23 is comma separated like print format 22, but channel 0 that contains the sum of all of the water column, is omitted. The file contains the relative frequency response for the first species selected.
  • Print format 24: Report format intended for estimating the backscatter at frequency "f" relative to other frequencies (i.e. the "relative frequency response). Print format 24 has the same print format as 22 and 23, but the data are not normalized to 38 kHz. This allows for normalization to other frequencies when 38 kHz data does not exist. Channel 0 (i.e. the sum channel) is omitted. The file contains data for the first species selected.
  • Print format 25: ICES format
  • Print format 26: Same as Print format 25, but using the AcousticCategory numerical code instead of the ICES code.
  • Print format 30: Report format intended for school analysis: compact print format sorted on object-number, date, time. The object-number identifies a school with the same object-number across the frequencies. The object-number also identifies the echogram that was visible when storing to the database.
  • Print format 31: Report format intended for school analysis. General output similar to print format 5, but sorted on object-number, date, time. Each file contains one species measured at one acoustic frequency.
  • Print format 32: Report format intended for school analysis. General output with similar content as print format 31, but with all data contained in a single line. Each file contains one species measured at one acoustic frequency.
  • Print format 40: Report format intended for analysis of vertical distribution. Data parallel to surface and bottom are in separate files.

Printing at reduced resolution

Some reports can be printed at reduced resolution if requested, and some cannot. Reports 1 - 19 can be printed at reduced resolution while 20 - 40 cannot

Use schools only

Use only data scrutinized as schools, and use school depth channels.

Use distance file extension in report file-names

Use distance file extension in report file-names, e.g. ListComScatter_F0380000_T2_L3205.0-3235.0.txt instead of ListComScatter_F0380000_T2.txt

Print formats

("%s") means string, ("%d") means integer, ("%f") means floating number, (NEWLINE) means line shift. ("%4d") means 4 positions are used to print an integer, (" %4d") means a leading space before the 4 positions of an integer, ("%02d") means that 2 positions are used to print an integer, and that the first position is zero if the integer is a single digit integer.
