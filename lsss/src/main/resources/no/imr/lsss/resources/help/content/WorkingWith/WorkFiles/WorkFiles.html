Work files

Work files are stored in WorkDir configured in [Survey configuration - Data files]. Each work file is associated with a raw data file through the file name.

Work file contents

The following list outlines the content of work files:

  • Regions:
    • Definitions of layers and schools.
    • School parameters.
    • Assignments of acoustic categories.
    • Labels.
  • Exclusion of ping ranges.
  • Frequency-dependent deletion of data.
  • Thresholds. Displayed by the echogram colorbar.
  • Bubble correction.
  • Database storing settings.
  • Comments. Stored to the database in the ObservationComment table.
  • Track editing and labels.

Merging multiple work files

Layers and schools that cross file boundaries will be stored in split parts in multiple work files. Conversely, when loading multiple work files, regions will be merged if certain criteria are met:

  • Layers will be merged across file boundaries if
    • The layers have the same object number.
    • The layers have the same interpretation.
    • The layers can be merged topologically.
  • Schools will be merged across file boundaries if
    • The schools have the same object number.

If there are multiple layers with the same object number, then new object numbers will be assigned to avoid duplicates.

workData.xml

The file workData.xml will be saved alongside the work files. This file contains data global for all work files, such as a counter used when assigning new object numbers.

Snap files

Prior to version 2.10.0, LSSS would also save snap files, which were copies of the work files at the time of storing to the database. LSSS 2.10.0 reads snap files, but saving will only write work files, and snap files will be deleted.
