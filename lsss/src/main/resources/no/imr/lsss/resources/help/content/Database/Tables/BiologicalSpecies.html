BiologicalSpecies

Name

BiologicalSpecies - Species of the database

Synopsis

struct BiologicalSpecies {
  short Nation;
  int   BiologicalSpecies;
  char  Initials[5];
  char  CommonName[80];
  char  EnglishName[80];
  char  LatinName[80];
  char  NODC[12];
  int   ITIS;
};

Description

This table contains information characterizing individual species - name, identification code, etc. The species are biological species. Since the content of the database table is seldom expanded, there is no GUI in LSSS to insert content.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • BiologicalSpecies - Unique identifier for biological species.
  • Initials - Short form species name.
  • CommonName - Complete species name in native language. Note that number of characters is limited.
  • EnglishName - Complete species name in English. Note that number of characters is limited.
  • LatinName - Complete species name in Latin. Note that number of characters is limited.
  • NODC - Internationally standardized species code (National Oceanographic Data Center).
  • ITIS - International standard species code (Integrated Taxonomic Information System).
