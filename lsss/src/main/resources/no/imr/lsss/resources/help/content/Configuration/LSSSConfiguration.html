Configuration

This section explains the different elements of the LSSS configuration. The configuration is organized in two parts:

  • Application configuration - Common for all surveys.
  • Survey configuration - Specific for each survey.

Access level

In the lower left corner of the configuration dialog, different access levels can be chosen:

  • Normal use: Only settings required for doing interpretation within a survey can be changed.
  • Survey setup: The settings required for defining a new survey can be changed.
  • Administrator mode: All settings can be changed.

The reason for the division into three access levels is to prevent an operator from accidentally changing important settings in the application. By using the three different levels, such changes become a more explicit action.
