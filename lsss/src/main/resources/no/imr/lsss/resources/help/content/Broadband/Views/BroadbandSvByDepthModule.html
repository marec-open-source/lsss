BB Sv(f, depth)

This view shows a heatmap of Sv as a function of frequency and depth for the current ping.

Description

The current ping is divided into depth intervals with size given by the Depth resolution parameter. For each depth interval, the Sv-frequency spectrum is computed in the same way as for the BB Sv(f) module. Each resulting grid cell in the (frequency, depth)-domain is then colored according to the echogram colorbar.

Settings

FFT settings

  • Frequency resolution: Horizontal grid size.
  • Depth resolution: Vertical grid size, used when computing Sv(f).
  • FFT window size: Size of the FFT window in units of pulse length.

Display settings

  • Use TVG: Plot Sv (with TVG) or Noise (Sv without TVG).
  • Auto-adjust axes: Automatically adjust the x-axis and y-axis when the plot is updated.
