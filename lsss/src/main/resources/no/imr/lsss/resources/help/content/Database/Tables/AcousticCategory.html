AcousticCategory

Name

AcousticCategory - Acoustic categories of the database

Synopsis

struct AcousticCategory {
  short Nation;
  short Platform;
  int   AcousticCategory;
  short Composite;
  char  Initials[5];
  char  EnglishInitials[5];
  char  CommonName[80];
  char  EnglishName[80];
};

Description

This table contains information characterizing individual acoustic categories - name, identification code etc. An acoustic category may be a fish-species (e.g. herring), a group of fish-species (e.g. Ha/Co - Haddock or Cod), a subgroup of a species of fish (e.g. 0Herr - Zero group herring, i.e. herring less than one year) or similar, a group of zooplankton (e.g. large fluid-like zooplankton), or similar.

Parameters

  • Nation - Unique nation identification code. Refer to the Nation database table.
  • Platform - Unique platform (vessel) identification code. Refer to the Platform database table.
  • AcousticCategory - Unique identifier for acoustic category.
  • Composite - Flag indicating if the acoustic category given by Nation-Category is a composition of several acoustic categories or not. If subcategories are assigned this parameter is set to 1, and with no subcategories it is set to 0.
  • Initials - Short form category name used by the Interpretation window and the printout programs.
  • EnglishInitials - Short form category name in English.
  • CommonName - Complete category name in native language. Note that number of characters is limited.
  • EnglishName - Complete category name in English. Note that number of characters is limited.
