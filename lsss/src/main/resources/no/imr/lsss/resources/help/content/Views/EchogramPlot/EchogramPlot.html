Echogram plot

This view is placed under the echogram, and can plot various functions defined from a ping to a real number.

Some of the available functions (such as Sv, TSC and TSU) depend on the mouse position in the echogram. These functions are evaluated at the depth corresponding to the mouse position (or the z coordinate for the bottom echogram).

The selected functions can also be exported.

Settings

  • Plot all channels: If unchecked, only the current channel is plotted for channel-dependent functions, such as sample interval, transmit power, etc.
  • Auto-adjust y-axis: Automatically adjust the y-axis when the plot is updated.
  • Gaussian smoothing Gaussian kernel standard deviation measured in plot points.
  • Various parameters, such as vessel speed, heave, transmit power, etc.

Roll: degrees-transmit-to-receive

This function indicates (averaged) roll from transmit to receive. It is intended to indicate the quality/usability of data from uncrewed surface vehicles (USV).
