Survey configuration

In this panel, the parameters for the current survey can be adjusted, or a new survey can be created.

When creating a new survey, all parameters except the survey title are optional. The parameters are there for later searches in the database, so it is recommended to use some reasonable values where possible.

  • Nation: Select the nation from a list.
  • Platform: After selecting the nation, select the platform (ship or stationary platform) from a list. If the platform does not exist, it can be created with the New platform button.
  • Survey number: The survey number. The number must be unique, since it is used as a key in the database together with Nation and Platform. When creating a new survey, an available number in the database will be selected by default.
  • Survey title: The survey title.
  • Start date (UTC) (optional): The start date of the survey. Today's date will be chosen by default.
  • Start time (UTC) (optional): The start time of the survey. 00:00 will be chosen by default.
  • Stop date (UTC) (optional): The end date of the survey. Today's date will be chosen by default.
  • Stop time (UTC) (optional): The end time of the survey. 23:59 will be chosen by default.
  • Northern survey boundary (N+, S-) (optional): The (approximate) northern boundary of the survey.
  • Southern survey boundary (N+, S-) (optional): The (approximate) southern boundary of the survey.
  • Western survey boundary (E+, W-) (optional): The (approximate) western boundary of the survey.
  • Eastern survey boundary (E+, W-) (optional): The (approximate) eastern boundary of the survey.
  • Short survey description (optional): A short description of the survey.

The start and end times can optionally specify seconds (using format HH:MM:SS) or even hundredths of a second (using format HH:MM:SS:XX).
