LSSS setup

The first time LSSS is started, some global settings must be initialized. These settings can be changed at any later time.

The LSSS setup wizard can later be started from the Help menu.

Main directory

The main directory is used as the default location for new surveys, and for configuration files.

See [Application configuration - Directories] for later changing the main directory.

See [Application configuration - Preprocessing] for later changing the configuration file directory.

Database

The database is needed when creating new surveys and for generating database reports.

See [Application configuration - Database] for later changing the database connection.
