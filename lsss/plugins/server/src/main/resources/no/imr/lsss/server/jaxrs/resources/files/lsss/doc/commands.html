LSSS server commands

This page lists the commands for the LSSS server.

Notes

  • All non-empty request and response bodies are JSON unless otherwise specified.
  • GET requests do not change the LSSS state. POST and DELETE requests do.

 List of resultsRuns the SQL query. Example: /lsss/database/sql?query=select * from nation

For the select and zoom commands, either the horizontal or the vertical coordinate can be unspecified.

Echogram point

An echogram point is a JSON object with two properties.

  • A horizontal coordinate. Alternatives:
    • time: string. Time in ISO 8601
    • pingNumber: integer. Ping number
    • vesselDistance: float. Vessel distance [nmi]
  • A vertical coordinate:
    • z: float. Depth [m] for the pelagic echogram, and range [m] from the bottom for the bottom echogram

Example: { "time": "2014-11-02T09:45:30Z", "z": 10 }

  • keepStoringSettings: boolean. Default = false.
 Deletes the current ping range from the database
POST /lsss/module/InterpretationModule/scrutiny Scrutiny Sets the scrutiny of the currently selected regions

Store request

A JSON object with these properties:

  • quality: integer
    • 1: High (Categories separable acoustically)
    • 2: Intermediate
    • 3: Low (Categories completely mixed acoustically)
  • frequencies: array of integers. The frequencies [kHz] to store

Example: { "quality": 1, "frequencies": [38, 70, 200] }

Ping mask

A JSON object with these properties:

  • A horizontal coordinate. Alternatives:
    • time: string. Time in ISO 8601
    • pingNumber: integer. Ping number
    • vesselDistance: float. Vessel distance [nmi]
  • depthRanges: array of float ranges

Example: { "time": "2014-11-02T09:45:30Z", "depthRanges": [ { "min": 10, "max": 20 }, { "min": 30, "max": 35 } ] }

Float range

A JSON object with these properties:

  • min: float
  • max: float

Example: { "min": 12.3, "max": 15.78 }

Selection request

A JSON object with these properties:

  • The operation for how the set of matched regions modifies the set of selected regions:
    • operation: {ADD, REMOVE, RETAIN, SET}. Default = SET.
  • Zero or more region matching criteria:
    • all: boolean. Optional. True matches all regions
    • layers: boolean. Optional. True matches all layers
    • schools: boolean. Optional. True matches all schools
    • selected: boolean. Optional. True matches selected regions
    • visible: boolean. Optional. True matches (partly) visible regions
    • ids: array of integer. Optional. Matches regions with any of these ids
    • labels: array of string. Optional. Matches regions with all these labels

The set of matched regions is the subset of all regions that match all specified criteria. No criteria match all regions.

Examples:

  • Select all regions: { "all" : true }
  • Deselect all regions: { "all" : false }
  • Deselect schools with labels "a" and "b": { "operation" : "REMOVE", "schools" : true, "labels" : [ "a", "b" ] }

Scrutiny

A JSON object with these properties:

  • channels: array of objects with these properties:
    • channelId: string
    • categories: array of objects with these properties:
      • id: integer
      • initials: string
      • assignment: float
  • restCategories: array of objects with these properties:
    • id: integer
    • initials: string

Notes when settings the scrutiny:

  • The "initials" properties are not used, and can be omitted
  • If "channelId" is omitted, then the corresponding assignments are applied to all channels
