LSSS server demo

Examples

URLDescription
/lsss/data/waitWaits until all requested pings are loaded
/lsss/database/reportGet all database reports
/lsss/database/report?reports=0,5&allSpecies=trueGet "Compact" and "ListUserFile05" database reports with all scrutinized species
/lsss/database/report/20Get the LUF20 database report
/lsss/moduleInfo about all modules
/lsss/module?hasData=trueInfo about modules that exposes data
/lsss/module?enabled=false&hasData=trueInfo about disabled modules that expose data
/lsss/module?enabled=true&hasData=true&data=trueInfo about enabled modules that expose data, including exposed data
/lsss/module/PelagicEchogramModule/imageScreenshot of PelagicEchogramModule
/lsss/module/BottomEchogramModule/imageScreenshot of BottomEchogramModule
/lsss/module/FrequencyResponseModule/dataThe data behind the FrequencyResponseModule display
/lsss/module/MapModule/imageScreenshot of MapModule
/lsss/module/MapModule/overlayInfo about all overlays of MapModule
/lsss/module/MapModule/overlay?enabled=true&data=trueInfo about all enabled overlays of MapModule, including exposed data
/lsss/module/TSModule/config/xmlAll configuration of the TSModule as XML
/lsss/module/TSModule/config/parameter/MinTSThe value of the MinTS parameter of TSModule
/lsss/regions/label?selected=trueLists the labels of all selected regions
/lsss/regions/region?visible=true&schools=trueLists the ids of visible schools
/lsss/survey/config/unit/DataConf/filesThe available data files
/lsss/survey/config/unit/DataConf/files/selectionThe currently selected files
/lsss/survey/config/unit/DataConf/parameter/DataDirThe current data directory
