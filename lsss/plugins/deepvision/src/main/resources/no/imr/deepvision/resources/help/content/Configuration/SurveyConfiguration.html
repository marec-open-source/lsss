Survey configuration

Data files

The DeepVisionDataDir is the root directory where the Deep Vision files are stored. The system will scan for Deep Vision files in the root directory and one level down. All files in those directories that meet the following criteria will be selected:

  • The file type is XML.
  • The root element of the XML document is called deepvision.

The XML file could be called deepvision.xml (or something.xml). With the root element called deepvision, the first lines could look like: 


<?xml version="1.0" encoding="UTF-8"?>
<deepvision xmlns:ns="http://www.deepvision.no/formats/deepvision/v1" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns:xsd="deepvision.xsd">
...
</deepvision>

Distance mapping

The following parameters decide how the Deep Vision data are positioned relative to the echosounder data:

  • Distance mapping: Switches how the Deep Vision path maps to the echogram. Choices:
    • Identity: The Deep Vision position is a fixed distance behind the ship.
    • Geographical: The recorded Deep Vision positions are used.
  • Distance behind ship: The fixed distance of the Deep Vision vessel behind the ship. Only used when the distance mapping is set to Identity.

Location of images

The format of the image files is specified by the 'fileformat' attribute of the 'frames' element in the Deep Vision file. Example: fileformat="jpg". If the format ends with '-zip', then the images are stored in zip files. Example: fileformat="jpg-zip".

If the images are not stored in zip files, then the expected location is: 

   File name: {time}.{fileformat}
   Directory: {Directory of Deep Vision file} / {Left or Right} / {folder}

where {time} and {folder} are attribute values of 'frame' elements in the Deep Vision file.

If the images are stored in zip files, then the expected location is: 

   File name: {time}.{fileformat without '-zip'}
   Zip file:  {Directory of Deep Vision file} / {Left or Right} / {folder}.zip

Additional user-defined data files

For each Deep Vision file, users can add an XML file with additional information that can be displayed in LSSS. Currently, the user can define filled circles that can be shown below the Deep Vision path. These circles can, for example, be used to indicate species type and amount. The additional files must meet the following criteria:

  • The file is placed in the same directory as the corresponding Deep Vision file.
  • The file type is XML.
  • The root element name is lsss-deepvision.

This additional XML file could, for example, be called lsss-deepvision.xml, and has a format that is illustrated in the example below: 


<?xml version="1.0" encoding="UTF-8"?>
<lsss-deepvision>
   <frames>
      <frame time="20150305065645195" color="#dc143c" size="20"/>
   </frames>
</lsss-deepvision>

The time attribute is used to associate with the corresponding frame in the Deep Vision file. The color has the form '#rrggbb' with hexadecimal color components. The size is the diameter of the circle in units of pixels.
