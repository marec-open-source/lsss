CAC0: Categorization configuration datagram

This datagram contains all categories referred to later by Categorization data datagrams. The categories are defined in the Categorization library.

Occurrences

Once, in the beginning of the file.

Source

  • Categorization module.

Contents

struct Cac0Datagram {
   DatagramHeader header; // CAC0
   byte categoryCount;
   Category[] categories;
};

struct Category {
   string name;   // Full name of this category
   string legend; // Short name displayed in e.g. the colorbar
   byte number;   // Referred to by Categorization data datagram
   byte red;
   byte green;
   byte blue;
};
