TS detection module

This module does single target detection.

Target detection is done on all channels.

The depth range for target detection is limited by:

  • The upper limit is the configured transducer blind zone.
  • The lower limit is the minimum of:
    • The configured transducer range.
    • The channel-specific bottom depth given by the BOT0 datagram.

New datagrams

TS detection datagram.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Detector type: The target detector type.
  • Min TS: Minimum corrected TS value to be detected [dB].
  • Pulse length determination level: Pulse length determination level [dB].
  • Min echo length: Minimum echo length (relative to pulse length). NB: may be << 1 for pulse compressed data!
  • Max echo length: Maximum echo length (relative to pulse length). NB: may be << 1 for pulse compressed data!
  • Max gain compensation: Maximum (one way) gain compensation [dB]. See Gain compensation estimation for details.
  • Do phase deviation check: Check this if phase deviation check should be performed.
  • Max phase deviation: Max phase deviation [phase steps]. See Computation of mechanical angles for details.
  • Max depth: Maximal depth of targets [m]. Optional, may be left blank.

Target detector types

SED

The input to the algorithm is TS values. First, find all the TS candidates, which are contiguous sequences of samples (echolines) above minimum TS value. The minimum TS value for the samples in an echoline is Min TS - 2 × Max gain compensation - Pulse length determination level.
For each TS candidate:

  1. Decrease the length of the echoline by backstepping by the pulse length determination level relative to the peak value of the echoline.
  2. Reject the candidate if the length of the echoline relative to the pulse length of the transducer is not within the values set in the parameters.
  3. If phase deviation checks should be performed: Reject the candidate if the standard deviation of the phase steps is not less than the specified value.
  4. Estimate the one-way gain compensation value. Reject the candidate if the gain compensation is higher than the specified value.
  5. Reject the candidate if there are multiple peaks in the echoline.
  6. Compute the compensated TS value of the peak value in the echoline. Reject the candidate if the compensated value is below the minimum TS value.
  7. If all tests pass, move the TS candidate to the list of accepted candidates.

Peak

The Peak algorithm detects targets by finding peaks on sample values. A sample is said to be a peak if:

  • It is a local maximum.
  • Its value is larger than other local maxima within a certain number of samples.

The values used in the peak detection:

  • Broadband data (complex FM):
    • Values: The (sector averaged) pulse compressed raw signal.
    • Sample count for peak search: The sample count in the filtered sent signal.
  • Narrowband data (complex CW):
    • Values: The (sector averaged) match filtered signal.
    • Sample count for peak search: Max echo length × Pulse duration / Sample interval.
  • Real data (sv and angles):
    • Values: Linear noise values (sv without TVG).
    • Sample count for peak search: Max echo length × Pulse duration / Sample interval.

The threshold for the required separation from other equally strong (or stronger) local maxima is determined using Ridler and Calvard's (1978) classical iterative threshold selection method.

The extension of the target is determined as the sample range spanning from the peak sample to the next samples above and below with a value lower than the peak value × 10 -Pulse length determination level / 20.

All targets fulfilling additional criteria on minimal corrected target strength at peak (Min TS) and maximal gain compensation (Max gain compensation), in addition to falling in the specified extended range (defined by Min echo length and Max echo length), are accepted. Filtering on phase deviation (enabled by Do phase deviation check) is not recommended for broadband data since angle information is only sensible for main peaks, but not on the side lobes.

Background

One-way gain compensation estimation

The gain compensation is estimated according to the following polynomial approximation to the first order Bessel function of the first kind:
     B(a, b) = 3.0103 ( x2 + y2 - 0.18x2y2)
where
     a is the alongship angle.
     b is the athwartship angle.
     x = 2a / BWa and BWa is the beam width alongship.
     y = 2b / BWb and BWb is the beam width athwartship.

Computation of mechanical angles

The 'electrical degree', e, is computed as
     e = i * 180 / 128
where
     i is the signed byte stored on the data file (the phase step).

The 'mechanical degree', m, is then computed as
     m = e / sensitivity - offset
where
     sensitivity is the angle sensitivity stored in the configuration datagram.
     offset is the angle offset stored in the configuration datagram.

Converting from Sv to TS

TS is computed from Sv as
     TS = Sv + 10 log (TVG(r) ) + 10 log ((c * tau * psi) / 2) + 2 SaCorr
where
     TVG(r) is the 20 log r time varying gain function.
     c is the speed of sound in water
     tau is the pulse length
     psi is the equivalent beam angle
     SaCorr is a calibration offset.
