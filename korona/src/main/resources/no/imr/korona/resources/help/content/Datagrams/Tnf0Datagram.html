TNF0: Track info datagram

This datagram contains information about one track.

Occurrences

At the end of each track.

Source

  • Tracking module.

Contents

struct Tnf0Datagram {
   DatagramHeader header; // TNF0
   int id;                // ID of this track
   short channel;         // The channel this track was detected on
   byte valid;            // 1 if this track is marked as valid, otherwise 0
   int pingsSinceFirst;   // Number of pings since the start of this track, relative to this ping
   int pingsSinceLast;    // Number of pings since the end of this track, relative to this ping
};
