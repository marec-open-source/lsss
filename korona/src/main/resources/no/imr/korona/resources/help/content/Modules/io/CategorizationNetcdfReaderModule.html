Categorization NetCDF reader module (beta)

Module for reading categorization data in netCDF-format.

NB: This module is in beta and can be incompatibly changed or removed in future versions.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Input file: The netCDF data is read from this file.
  • Main frequency: The channel with the main frequency is used for converting range to depth.
