IDX0: Ping index datagram

This datagram contains ping index information.

Occurrences

Once per ping in the idx file.

Source

  • The echosounder.
  • KORONA.
  • LSSS.

Contents

struct Idx0Datagram {
   DatagramHeader header; // IDX0
   int pingNumber;
   double vesselDistance; // [nmi]
   double latitude;       // [deg]. Value 0 indicates missing value
   double longitude;      // [deg]. Value 0 indicates missing value
   long fileOffset;       // Byte offset in the raw file
};
