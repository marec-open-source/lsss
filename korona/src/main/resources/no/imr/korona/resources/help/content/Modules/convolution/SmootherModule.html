Smoother module

Performs smoothing by convolution.

Requirements

  • Depth datagrams, Dep0Datagram, see Bottom detection module, if parameter Mask bottom is selected.
  • Noise datagrams, Nqp0Datagram, see NoiseQuantificationModule, if parameter Mask noise is selected.
  • Region border datagrams, RegionBorderDatagram, see School detection module, if parameter Mask region is selected.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Only last channel: If selected only the last channel is processed, otherwise all channels are processed.
  • Mask pelagic: Exclude samples above bottom.
  • Mask bottom: Exclude samples below bottom.
  • Mask second bottom: Exclude samples below 10 m above second bottom echo.
  • Mask noise: Exclude samples below noise threshold.
  • Mask region: Exclude samples in connection with regions.
    Allowed values: { none, inside, outside }
  • Mask track: Exclude samples in connection with tracks.
    Allowed values: { none, inside, outside }
  • Min ping: Number of pings used ≥ 2 × Min ping + 1.
    Allowed values: Min ping ≥ 0
  • Max ping: Number of pings used ≤ 2 × Max ping + 1.
    Allowed values: Max ping ≥ 0
  • Horizontal kernel type: Convolution kernel type horizontally.
    Allowed values: { gaussian, tophat }
  • Vertical kernel type: Convolution kernel type vertically.
    Allowed values: { gaussian, tophat }
  • Horizontal width: Convolution kernel width in meters.
    Allowed values: Horizontal width > 0
  • Vertical width: Convolution kernel height in meters.
    Allowed values: Vertical width > 0
  • Logarithmic values: If checked use log(sv), otherwise use (linear) sv.
