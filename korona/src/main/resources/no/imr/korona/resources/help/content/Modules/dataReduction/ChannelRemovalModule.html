Channel removal module

Removes specified channels.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Channels: Comma-separated list of channel numbers.
  • Channels from end: Comma-separated list of channel numbers from the end. (1 = last channel, 2 = second last channel, etc.)
  • Frequencies: Comma-separated list of kHz.
  • Data type: The data type to select. NB: Only the first few pings will determine if a channel is selected.
  • Transmit mode: The transmit mode to select. NB: Only the first few pings will determine if a channel is selected.
  • Keep specified: If selected, then keep only the specified channels.
