Datagrams

The datagrams listed here include all custom datagrams defined by KORONA, and some key datagrams from the echosounder. For further information about the echosounder datagrams, please refer to the documentation provided by the manufacturer.

BOT0: Per channel bottom depths
CAC0: Categorization configuration
CAD0: Categorization data
CAS0: Categorization school
CDS0: Computing description
CON0: Configuration
DEP0: Coordinated bottom
IDX0: Ping index
LSSS/10: TS detection
LSSS/11: Echo lines
NME0: NMEA
NQP0: Noise quantification
PIC0: Plankton inversion config
PID0: Plankton inversion data
RAW0: Sample data
RBR0: Region border
RNF0: Region info
RTC0: Region table of contents
TBR0: Track border
TNF0: Track info
TTC0: Track table of contents
Unknown datagram

Definitions

A file with datagrams is read with byte order little-endian. The datagrams form a sequence of the following structure: 

struct DatagramContainer {
   int size;          // Size of datagram in bytes
   Datagram datagram;
   int size;          // Size of datagram in bytes (repeated)
};

struct Datagram {
   DatagramHeader header;
   // Content specific to the different datagram types
};

struct DatagramHeader {
   int type;    // Can also be interpreted as 4 ascii characters, e.g. 811024722 = "RAW0"
   ntTime time;
};

The data types used in the datagrams are as follows:

  • byte 8-bit integer
  • short 16-bit integer
  • int 32-bit integer
  • long 64-bit integer
  • float 32-bit floating point number (IEEE 754)
  • double 64-bit floating point number (IEEE 754)
  • ntTime 64-bit integer representing number of 100-nanosecond intervals since January 1, 1601 UTC
  • string 0-terminated string encoded as IS0-8859-1
