Tracking module

Tracks single targets. Tracking is performed on a single frequency using a chosen tracker type, in the following steps:

  1. target detection
  2. target filtering
  3. track initialization
  4. track association
  5. track acceptance/rejection

If the Tracking module is applied to data without angles, then both the alongship angle and the athwartship angle are assumed to be zero for all samples. This implies zero directivity correction, hence corrected TS equals uncorrected TS.

Parameters

General settings

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Tracker type: The tracker to be used.
  • Frequency [kHz]: The frequency on which to do tracking.

Tracker types

The choice of the tracker affects the target detection and track initialization. All the other stages of the tracking algorithm are independent of this choice.

The following tracker types are available:

  • Aggregation: This tracker detects targets in each ping based on target strength, extracting all samples with target strength greater than Min TS, provided their gain compensation is less than Max gain compensation.
  • SED: This tracker uses the SED target detector in the TS detection module.
  • Peak: This tracker uses the Peak target detector in the TS detection module.
  • TSModule: This tracker uses the targets detected by a TS detection module earlier in the module processing pipeline.

Platform settings

  • Platform motion type: The type of movement the platform undergoes.

The following motion types are available:

  • Stationary: This choice assumes that changes in the position and orientation of the platform from ping to ping are negligible. Tracking is performed in the transducer's coordinate system.
  • Floating: This choice assumes that vertical changes in the position of the platform from ping to ping are negligible. Tracking is performed in a local coordinate system, after correcting for heading, pitch, roll and heave.
  • Moving: This choice assumes that changes in the position and orientation of the platform from ping to ping are non-negligible. Tracking is performed in a global coordinate system.

Target detector settings

Common parameters for all trackers, except TSModule:

  • Min TS: Minimum TS value to be detected [dB].
  • Max gain compensation: Maximum (one way) gain compensation [dB].

In addition to the common settings, the following parameters can be set for Aggregation, and Peak trackers:

  • Pulse length determination level: Pulse length determination level [dB].
  • Min echo length: Minimum echo length (relative to pulse length). NB: may be << 1 for pulse compressed data!
  • Max echo length: Maximum echo length (relative to pulse length). NB: may be << 1 for pulse compressed data!
  • Do phase deviation check: Check this if phase deviation check should be performed.
  • Max phase deviation: Max phase deviation [phase steps].

The recommended presets for the target detection settings of the chosen tracker can be loaded by clicking on the Set presets button.

Target filtering settings

All targets not satisfying the here set condition are rejected post-detection. The settings are independent of the chosen tracker.

  • Max TS: Maximum corrected TS value [dB].
  • Max depth: Maximum target depth at peak position [m].
  • Max alongship angle: Maximum alongship angle [deg].
  • Max athwartship angle: Maximum athwartship angle [deg].

Track initialization settings

Settings governing the initialization of new tracks. In this stage, nearby targets may also be merged.

Aggregation tracker:

  • Initiation gate function: Definition of the gate function for merging of detected targets.
  • Initiation min length: Minimal number of targets to be merged for new track.

SED, and Peak tracker:

No settings. All filtered detected targets that cannot be associated with an existing track are initialized as new tracks without merging.

Track association settings

Settings governing the construction and termination of tracks.

  • Gate function: Definition of the gate function for track association.
  • Alpha beta estimator: Definition of the predictor-corrector scheme for track association.
  • Max missing pings: Nm - Maximum number of missing pings in a row before termination.

Aggregation tracker:

  • Max missing samples: Ne - Maximum number of missing samples in a single ping before termination.

Track acceptance settings

Settings for final acceptance/rejection of a terminated track.

  • Max missing pings fraction: MN - Maximum acceptable ratio of missing pings to track length.
  • Min track length: TL - Minimum acceptable track length.
  • Min sample to length fraction: NL - Minimum acceptable ratio of total number of samples to track length.

Background

Gate function

The difference between two targets i and j is calculated as:

εij = yi - yj

where yi = [ α β r TS ], α = alongship angle, β = athwartship angle, r = range, TS = target strength.
