Getting started with KORONA

The processing done by KORONA can either be done as batch processing, using KORONA relay, or interactively using KORONA playbox.

Viewing a data file

  1. Start KORONA relay and specify the location of data files in "Source directory". A list of available data files in that directory will then appear below.
  2. Select one of the files in the list by clicking on it.
  3. Click the "KORONA playbox" button to start KORONA playbox.

Computation modules

Computation modules are specified by the "Module configuration" file in the Config file settings.

  1. Click the "Edit" button for the "Config file settings" file in KORONA relay.
  2. Specify a "Module configuration" file by one of
    • Click the "Browse" button to select an existing file.
    • Click the "Edit" button to specify modules using the module editor.
