Echo line compression module

This module makes resulting data files smaller by discarding low values. Only samples above a given threshold will be saved. This module should normally be the last module.

To increase the compression, other modules that set samples to low values can be used prior to this module, such as: Noise remover module, Thresholding module

New datagrams

  • Echo line datagram - One datagram for each channel for each ping.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Threshold: Only samples above the threshold will be kept.
