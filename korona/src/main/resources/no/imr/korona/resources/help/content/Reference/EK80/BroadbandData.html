EK80 broadband data

This section contains details about the processing of broadband data produced by the Simrad EK80 echosounder.

Computation of Sv

Let yi be the complex sample value of sector i ∈ [1, n].
Let y = (1/n) ∑ yi be the average value over all sectors and s the (ideal) transmitted chirp signal.
Let furthermore ypc= y * s̅-1 be the pulse compressed received signal, where * denotes the convolution of two signals and ¯-1 the combined conjugation and time reverse operator.
Let p = κ|ypc|2, with κ = (n / 8) ( (Rwbt,rx + Ztrd) / Rwbt,rx)2 / Ztrd.
Then
     Sv = 10 log10(p) + CSv + TVGSv
where
CSv = -2 Gfc - Ψfc - 10 log10( (ptx λ2 c τeff) / (32 π2) )
     Gfc = Gain at Centre frequency
     Ψfc = Equivalent beam angle at Centre frequency
     ptx = Transmit power
     λ = c / fc
     c = Sound speed
     fc = Centre frequency
     τeff = Effective pulse duration

TVGSv = 20 log10(rTVG) + 2 α rTVG
     rTVG = Sample range - τ c / 4
     α = Absorption coefficient
     τ = Pulse duration

Computation of TS

The target strength is derived using the following formula
     TSu = 10 log10(p) + CTS + TVGTS

for uncorrected target strength, where
CTS = -2 Gfc - 10 log10( (ptx λ2) / (16 π2) )

TVGTS = 40 log10(rTVG) + 2 α rTVG
and
     TSc = TSu + 20 log102 (ρξ + ρχ - 0.18 ρξ ρχ)
for beam position corrected target strength, where
     ξ = along angle
     χ = athwart angle
     ρξ = (2 ξ / bwξ,fc)2
     ρχ = (2 χ / bwχ,fc)2
     bwξ,fc = along beam width at centre frequency
     bwχ,fc = athwart beam width at centre frequency
and remaining symbols as already defined

Computation of Sv(f)

Let ((ypc)ℓ)ℓ be a signal segment with ℓ = ℓ1,…,ℓm the sample index of the signal in a single ping. Let furthermore spc be the pulse compressed (or autocorrelated) transmitted chirp signal as above and ℱ the discrete Fourier transform (DFT) operator.
Then, the Sv-spectrum Sv(f) is computed as follows
    Sv(fk) = 10 log10 ( κ|ℱ{ypc}k / ℱ{spc}k|2)
         - 10 log10( (ptx c λfk2) / (32 π2) )
         - 10 log10(m T)
         + 2 r αfk,d - 2 Gfk - Ψfk
with
     fk = kth DFT frequency
     λfk = c / fk, wavelength
     T = sampling interval
     r = range of sample corresponding to signal segment midpoint
     αfk = absorption coefficient at fk
     Gfk = Gain at fk
     Ψfk = Equivalent beam angle at fk
and remaining symbols as already defined.

Computation of TS(f)

Let ((ypc)ℓ)ℓ again be a signal segment with ℓ = ℓ1,…,ℓm the sample index of the signal in a single ping and spc and ℱ as above.
Then, the TS-spectrum TS(f) is computed as follows
     TS(fk) = 10 log10 ( κ|ℱ{ypc}k / ℱ{spc}k|2)
         - 10 log10( (ptx λfk2) / (16 π2) )
         + 40 log10(rp)
         + 2 rp αfk,dp - 2 Gfk
         + 20 log102 (ρξp + ρχp - 0.18 ρξp ρχp)
with
     ξp = along angle of sample corresponding to peak of signal
     χp = athwart angle of sample corresponding to peak of signal
     ρξp = (2 ξp / bwξ,fk)2
     ρχp = (2 χp / bwχ,fk)2
     rp = range of sample corresponding to peak of signal
     αfk = absorption coefficient at fk
and remaining symbols as already defined.
