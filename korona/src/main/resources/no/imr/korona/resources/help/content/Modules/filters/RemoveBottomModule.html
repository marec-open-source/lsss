Remove bottom module

Module for removing data around the detected bottom.

Data in three different intervals can be removed:

  • Above the upper bottom limit
  • Between the upper and the lower bottom limits
  • Below the lower bottom limit

If Automatic depth range is deselected, then Start depth and End depth can be specified manually, and these will be used as upper and lower bottom limits.

Requirements

Depth datagrams, Dep0Datagram, must be computed, see Bottom detection module.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Logarithmic values: Use log(sv) or sv.
  • Show details: Shows more detailed settings (Only last, Channels to process, Automatic depth range, Start depth, End depth).
  • Only last: When true, only the last channel is processed; if false, all channels are processed.
  • Channels to process: Process the n last channels (-1 for all channels).
  • Automatic depth range: If true and Bottom detection module is used, then the range goes to the detected seabed, if true and Bottom detection module is not used, the range goes to the max depth of the ping.
  • Start depth: Start depth in meters for the filter.
  • End depth: End depth in meters for the filter.
  • Use neighbours: Use minimum depth from current ping and neighbours.
  • Above: Upper bottom limit is this many samples above bottom.
  • Below: Lower bottom limit is this many samples below bottom.
  • Remove above bottom: Remove values above upper bottom limit.
  • Remove bottom: Remove values between upper and lower bottom limits.
  • Remove below bottom: Remove values below lower bottom limit.
  • Fill value: Value to set pixels to.
