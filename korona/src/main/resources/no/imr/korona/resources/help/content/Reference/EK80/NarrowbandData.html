EK80 narrowband data

This section contains details about the processing of narrowband data produced by the Simrad EK80 echo sounder.

Computation of Sv

Let yi be the complex sample value of sector i ∈ [1, n].
Let y = (1/n) ∑ yi be the average value over all sectors.
Let p = κ|y|2, with κ = (n / 8) ( (Rwbt,rx + Ztrd) / Rwbt,rx)2 / Ztrd.
Then
     Sv = 10 log10(p) + constant + TVG
where
constant = -2 G - 2 Sa,corr - Ψ - 10 log10( (ptx λ2 c τeff) / (32 π2) )
     G = Gain
     Sa,corr = Sa correction
     Ψ = Equivalent beam angle
     ptx = Transmit power
     λ = c / f
     c = Sound speed
     f = Frequency
     τeff = Effective pulse duration

TVG = 20 log10(rTVG) + 2 α rTVG
     rTVG = Sample range - τ c / 4
     α = Absorption coefficient
     τ = Pulse duration

Computation of split beam angles

The complex samples values are used directly for computing split beam angles.
