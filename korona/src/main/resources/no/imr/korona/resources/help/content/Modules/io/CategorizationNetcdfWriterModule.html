Categorization NetCDF writer module (beta)

Module for writing categorization data in netCDF-format.

NB: This module is in beta and can be incompatibly changed or removed in future versions.

NetCDF-C library

This module requires the NetCDF-C library for writing files in the NetCDF-4 format. If this version of KORONA does not include the NetCDF-C library, please consult these instructions.

Automatic range

The parameters Delta range and Max range are optional. If unspecified, these values are determined from the sample distance and max range in the input data.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Output directory name: The netCDF files are written to this subfolder in the destination directory.
  • Main frequency: A comma-separated list of prioritized candidates for the main frequency. If unspecified, the first channel is used. The channel with the main frequency is used for converting depth to range.
  • Delta range: Leave blank to determine automatically.
  • Max range: Leave blank to determine automatically.
