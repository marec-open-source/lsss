LSSS/11: Echo line datagram

This datagram is similar to the RAW0 datagram, but contains only a subset of the samples.

Occurrences

Once per ping per channel.

Source

  • Echo line compression module.

Contents

struct EchoLineDatagram {
   DatagramHeader header;     // LSSS
   short subDatagramType;     // 11
   RAW0 parameters;           // RAW0 parameters, but not sample values
   int echoLineCount;         // The number of echo lines
   EchoLine[echoLineCount] echoLines;
};

struct EchoLine {
   int startSample;              //
   int sampleCount;              //
   short[sampleCount] power;     // Power values as in the RAW0 datagram
   byte[2 * sampleCount] angles; // Only present if RAW0 mode & 2 != 0
};
