Thresholding all channels module

This module masks out values on all channels if some channels are too weak or too strong.

If a channel has a sample value below or above the specified threshold, then the corresponding samples on all channels are set to the specified replacement value.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Criterion: How to test values (>, ≥, ≤, <).
  • Threshold: The threshold value [dB].
  • Replacement: The replacement value [dB].
  • Min frequency: Minimum frequency [kHz] for testing against the threshold.
  • Max frequency: Maximum frequency [kHz] for testing against the threshold.
