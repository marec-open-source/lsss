Display module

This module displays all data channels as done by KORONA playbox. If no display modules are specified, then KORONA playbox will add a Display module at the end.

One reason for using this module explicitly is for visually comparing the data before and after some processing. For example, the module configuration

Display module ➔ Smoother module ➔ Display module

will display the data before and after smoothing.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
