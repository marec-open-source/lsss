Ping collapsing module

This module collapses sequential pinging. Consecutive pings with sample data only on different channels, will be combined into one ping.

The motion data (heave, roll, pitch, heading) of the resulting collapsed ping will not contain the varying motion data of the original set of several uncollapsed pings.

Collapsing pings necessarily changes the ping-count compared to the original, and therefore the ping-count starts at 1 if this module is used.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
