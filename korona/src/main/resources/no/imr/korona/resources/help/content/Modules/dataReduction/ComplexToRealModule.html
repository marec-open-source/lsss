Complex to real module

This module converts complex broadband or narrowband data to sv values and angles.

Sv is computed according to the formulas for broadband data and narrowband data

Conversion of broadband data to multiple single frequency datagrams per channel is possible by using the Broadband splitter module.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Compute angles: If selected, then angles are computed.
  • Keep broadband: If selected, then broadband data is not converted to real data.
