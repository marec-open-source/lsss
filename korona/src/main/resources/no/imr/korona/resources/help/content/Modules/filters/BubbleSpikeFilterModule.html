Bubble spike filter module

A module for removal of narrow vertical spikes in the echogram, typically caused by bubble clouds that block the sound below the ship.

This filter works in a similar way as the Spike filter module, except that it is looking for vertical structures that are significantly weaker than the surroundings (in contrast to the Spike filter module that looks for vertical structures that are stronger).

A sample is considered a spike if two criteria hold:

  1. The current search column is sufficiently weaker than the neighbouring search columns, i.e.,
    Neighbouring search column median < Current search column median + VerticalDelta
    is true for at most one neighbouring search column.
  2. The current sample is sufficiently weaker than the search window, i.e.,
    Current sample value < search window median - TotalDelta

Parameters

See Spike filter module for a listing of parameters.
