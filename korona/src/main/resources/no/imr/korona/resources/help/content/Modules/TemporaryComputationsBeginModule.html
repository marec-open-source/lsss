Temporary computations begin module

This module marks the start of temporary computations. For each ping, copies of the Raw0Datagrams are made. Subsequent changes to Raw0Datagrams are reverted by a Temporary computations end module. New datagrams, however, for example from seabed detection, region detection or categorization, are kept.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
