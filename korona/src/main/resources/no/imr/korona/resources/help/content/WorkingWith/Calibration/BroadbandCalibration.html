Broadband calibration

LSSS allows for calibration of a number of parameters used in different broadband calculations by adding appropriate XML elements to a file "calibration.xml" to be placed in the same directory as the raw data files.

Values given in the file are interpolated linearly between frequencies. Outside the frequency range covered in the calibration, constant extrapolation applies. If the calibration file does not exist or does not contain calibration information for all parameters, the values are estimated using formulae based on nominal parameter values.

Complete example

<calibration>
   <case channel="2">
      <broadband>
         <g>
            <case hz="180000" g="22.04"/>
            <case hz="200000" g="22.5"/>
            <case hz="220000" g="22.9"/>
         </g>
         <ztde>
            <case hz="180000" ztde="75.1"/>
            <case hz="200000" ztde="75.25"/>
            <case hz="220000" ztde="75.31"/>
         </ztde>
         <eba>
            <case hz="180000" eba="-20.08"/>
            <case hz="200000" eba="-21.00"/>
            <case hz="220000" eba="-21.83"/>
         </eba>
         <albw>
            <case hz="180000" albw="7.78"/>
            <case hz="200000" albw="7.00"/>
            <case hz="220000" albw="6.36"/>
         </albw>
         <atbw>
            <case hz="180000" atbw="7.78"/>
            <case hz="200000" atbw="7.00"/>
            <case hz="220000" atbw="6.36"/>
         </atbw>
         <alao>
            <case hz="180000" alao="0.55"/>
            <case hz="200000" alao="0.70"/>
            <case hz="220000" alao="0.81"/>
         </alao>

            <case hz="220000" atao="1.22"/>
         </atao>
      </broadband>
   </case>

Correction formulae

The here given formulae are used to estimate the value of some frequency-dependent parameters of broadband data, if no broadband calibration is specified. The values of the parameter at a given frequency f are estimated from the parameter value at the nominal frequency (denoted by the subscript "nom").

Gain

g(f) = gnom + 10 log10(f / fnom)

Equivalent beam angle

ψ(f) = ψnom + 20 log10(fnom / f)

Beam width (either axis)

bwaxis = 2 arcsin( sin(bwaxis,nom / 2) · (fnom / f) )

Angle offset (either axis)

aoaxis(f) = aoaxis,nom
