Filter 3×3 module

This module applies a 3×3 filter. Either choose a filter from the dropdown menu or specify one manually by setting all 3×3 values.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Logarithmic values: Use log(sv) or sv.
  • Show details: Shows more detailed settings (Only last, Channels to process, Automatic depth range, Start depth, End depth).
  • Only last: When true, only last channel is processed, if false all channels are processed.
  • Channels to process: Process the n last channels (-1 for all channels).
  • Automatic depth range: If true and Bottom detection module is used, then the range goes to the detected seabed, if true and Bottom detection module is not used, the range goes to max depth of the ping.
  • Start depth: Start depth in meter for filter.
  • End depth: End depth in meter for filter.
  • Filter type: Specifies what filter to use
    Allowed values: { User defined, /*smooth1*/{{1,2,1},{2,1,2},{1,2,1}}, /*smooth2*/{{1,1,1},{1,1,1},{1,1,1}},
    /*lowpass*/{{1,2,1},{2,4,2},{1,2,1}}, /*sharpen*/{{-1,-1,-1},{-1,9,-1},{-1,-1,-1}},
    /*Laplacian edge (Deltasquared)*/{{1,-2,1},{-2,4,-2},{1,-2,1}},
    ... }
  • 00: matrix value.
  • 01: matrix value.
  • 02: matrix value.
  • 10: matrix value.
  • 11: matrix value.
  • 12: matrix value.
  • 20: matrix value.
  • 21: matrix value.
  • 22: matrix value.
