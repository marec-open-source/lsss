LSSS/10: TS detection datagram

This datagram contains single target detections.

Occurrences

Once per ping per channel.

Source

  • TS detection module.

Contents

struct TsDatagram {
   DatagramHeader header; // LSSS
   short subDatagramType; // 10
   int channel;           // The channel the detection was performed on
   int detectionCount;    // The number of detections
   TsDetection[detectionCount] detections;
};

struct TsDetection {
   float minDepth;   // [m]
   float maxDepth;   // [m]
   float peakDepth;  // [m]
};
