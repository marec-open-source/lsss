TBR0: Track border datagram

This datagram contains tracking info per ping.

Occurrences

Once per ping per track.

Source

  • Tracking module.

Contents

struct Tbr0Datagram {
   DatagramHeader header; // TBR0
   int id;                // ID of this track
   short channel;         // The channel this track was detected on
   float minDepth;        // [m]
   float maxDepth;        // [m]
   float peakDepth;       // [m]
};
