Median noise quantification module

This module can be used to quantify noise while the sonar operates in active mode.

The noise is quantified by picking a user defined number of equidistant samples per beam over a specified number of pings and computing the median. Only the outer samples of the beam are used. If the maximum range of a beam is denoted MR, and the user specifies a detection distance of x meters, only the samples in the range [MR-x, MR] is used.

The module creates and updates noise files per input file, per day and per survey. The files are written to at the end of the processing of the current file, and are placed in a subdirectory to the processed files.

NB: This module creates noise datagrams, the noise is removed with the NoiseRemoverModule.

New datagrams

  • Noise quantification datagrams, Nqp0Datagram.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Ping history [# pings]: Number of historical pings to use when computing new noise values.
  • Noise samples per beam: Number of samples to extract per beam for noise calculation (median).
  • Detection distance [m]: The distance for each beam used for noise detection.
  • Innermost distance: Whether to use the innermost or outermost part of the beam.
