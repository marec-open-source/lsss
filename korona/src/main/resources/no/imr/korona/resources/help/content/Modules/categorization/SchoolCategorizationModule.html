School categorization module

Module for performing categorization of whole schools.

Requirements

  • Region border datagrams, RegionBorderDatagram, see School detection module.
  • Region info datagrams, RegionInfoDatagram, see School detection module.
  • Categorization module, see Categorization module, must be before this module in the module setup.

New datagrams

  • A school categorization datagram, Cas0Datagram, for each detected region that has not been classified as multi-species. If the module has been unable to determine whether the region is single- or multi-species, the region is classified as uncategorized.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Use cell categorization: If enabled, use cell as input to school categorization.
  • Horizontal cell size: Cell size in number of pings.
  • Vertical cell size: Cell size in number of samples.
  • Upper sample offset: Number of samples excluded at the top of a region.
  • Lower sample offset: Number of samples excluded at the bottom of a region.
  • Horizontal offset: Number of pings excluded at the left and right edges of a region.
  • Secondary category fraction: Fraction of cells in a region that can be allowed to be different from the dominant category.
  • School categorization distribution: Distribution to use when categorizing whole schools.
    Allowed values: { CELL, SCHOOL }
  • Fill factor for cells: The fill factor of cells must be above this value for cells to be used in the analysis of schools.
  • Minimum fraction categorized cells: The fraction of categorized cells has to be above this factor for the school to be categorized.
  • Minimum number of cells: If the number of cells is lower than this, the data will be merged.
  • Enable the uncategorized category: If enabled, the schools where it cannot be determined if they are single or multi species are set to this category. Otherwise, no region category is given.
  • Enable the unknown category: If enabled, the unknown category can be used as a valid school category for schools determined to be single species. Otherwise, no region category is given.

References
