NetCDF writer module (beta)

Module for writing data in netCDF-format.

NB: This module is in beta and can be incompatibly changed or removed in future versions.

NetCDF-C library

This module requires the NetCDF-C library for writing files in the NetCDF-4 format. If this version of KORONA does not include the NetCDF-C library, please consult these instructions.

Automatic range

The parameters Delta range and Max range are optional. If unspecified, these values are determined from the sample distance and max range in the input data.

  • If Writer type = Gridded, the first available ping on the Main frequency is used.
  • If Writer type = Channel groups, the first available ping on each channel is used for the corresponding output channel group.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Output directory name: The netCDF files are written to this subfolder in the destination directory.
  • Main frequency: The channel with the main frequency is placed first in the output file. If unspecified, the first channel is used.
  • Writer type: How to structure the output data.
  • Gridded output type: Output data in addition to the basic information.
  • Channel group output type: Output data in addition to the basic information.
  • Delta range: Leave blank to determine automatically.
  • Max range: Leave blank to determine automatically.
  • FFT window size: Size of the FFT window in units of pulse length.
  • Delta frequency: Resolution of the broadband frequency array.
  • Write angles: If selected, then the output data will include arrays for alongship and athwartship angles.
