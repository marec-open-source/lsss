Broadband splitter module

This module splits the frequency band of each broadband data channel into narrower frequency bands and saves each of them as a single frequency channel.

Two different methods for computing sv for the split bands are available: Bandpass filtering and gliding FFT window.

Configuration files

This module requires a configuration file containing frequency bands to be converted to single frequency data, specified by their nominal frequency, their start frequency, and their stop frequency.

The broadband notch filters configuration file is optional, and only used with the Gliding FFT window method.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.

Split bands

  • Auto split: Split the original broadband channels into equally large sub-bands.
  • Split count: The number of single frequency channels created from each broadband channel.
  • Split bandwidth: Bandwidth of the auto-split bands. The default is channel bandwidth / Split count.
  • Stopband distance: Distance between the passband and the stopbands, i.e. the totally attenuated frequencies, in kilohertz.
  • Min bandwidth: Do not generate single frequency data from bands narrower than the specified bandwidth.

Data reduction

  • Downsampling: Choose downsampling method.
  • Downsampling factor: The downsampling factor. Only applicable when Downsampling is set to FACTOR.
  • Downsampling sample size: Downsampling is done with a downsampling factor that gives approximately this sample size. Only applicable when Downsampling is set to SAMPLE_SIZE.
  • Compute angles: Whether angles should be computed.

Computational method

  • Computational method: Method for computing sv for each split band. Available methods: BANDPASS_FILTERING and GLIDING_FFT_WINDOW.
  • FFT window size: Size of the FFT window in units of pulse length. Only applicable when Computational method is set to GLIDING_FFT_WINDOW.

Bandpass filtering method

The splitting of the original frequency band is performed by bandpass filtering the pulse compressed signal and computing sv at the centre frequency of this passband. Angles are also computed on these bandpass filtered data.

It is worth noting that the width of the sub-bands can affect the spatial resolution of the output. Narrower bands can result in worse resolution.

Furthermore, the width of the bands is limited by the inverse of the pulse length. In order to yield meaningful results, the bandwidth of the generated frequency bands should not be below this number. E.g. for a pulse length of 2 milliseconds, the minimal bandwidth is 500 Hz.

Other

  • Effective pulse length: The effective pulse length is calculated from the restricted sent pulse.
  • Transducer gain: The transducer gain is corrected to correspond to the centre frequency of each sub-band.

Gliding FFT window method

This method uses a gliding FFT window for computing sv in the split bands:

  1. Compute sv(f) for each resulting sample. The FFT window used has the configured size, and is centered around the sample.
  2. Find the usable frequency set for each split band. This is the split band minus any optionally configured notch filter bands. Therefore, when using this method, the Broadband notch filter module should not be used.
  3. Compute the average of sv(f) for the usable frequency set.

Because this method is computationally demanding, it might be advisable to use downsampling.

Angles are computed the same way as for the bandpass filtering method.
