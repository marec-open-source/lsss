Broadband splitter bands

Used by the Broadband splitter module.

One or both of frequencyStart and frequencyStop may be left blank. Unspecified values will be derived from the actual input data:

  • If both frequencyStart and frequencyStop are left blank, then the frequency band containing frequencyNominal is used. If several frequency bands contain frequencyNominal, then the band with center frequency closest to frequencyNominal is used.
  • If frequencyStart is blank, then the start of the frequency band containing frequencyStop is used. If several frequency bands contain frequencyStop, then the maximum is used.
  • If frequencyStop is blank, then the end of the frequency band containing frequencyStart is used. If several frequency bands contain frequencyStart, then the minimum is used.

Example XML file

<?xml version="1.0" encoding="UTF-8"?>
<splitterBands>
   <band frequencyNominal="70" frequencyStart="60" frequencyStop="75"/>
   <band frequencyNominal="170" frequencyStart="150" frequencyStop="180"/>
   <band frequencyNominal="200" frequencyStart="180" frequencyStop="230"/>
</splitterBands>
