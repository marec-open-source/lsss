DEP0: Coordinated bottom datagram

This datagram contains the depth of the coordinated bottom. Bottom depths per channel are given by the BOT0 datagram.

Occurrences

Once per ping.

Source

  • Bottom detection module.

Contents

struct Dep0Datagram {
   DatagramHeader header; // DEP0
   float depth;           // The detected bottom depth [m]
   float minimumDepth;    // The minimum bottom depth [m]
};
