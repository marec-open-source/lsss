Expression module

Creates a new channel defined as an expression of the existing channels.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Expression: An expression of the (linear) sv values. Use C1, C2, ..., or F18, F38, ...
    If multiple expressions are specified, then the first expression with all variables available is used.
    All functions in java.lang.Math are available.
    Examples:
    C1
    (C1 + C2) / 2
    C1 / C5 + F70 - C4
    C6 * log10(C2) / pow(C3, F364)
