Noise visualization module

Visualizes noise parameters in a separate window.

Requirements

  • Noise quantification datagrams, Nqp0Datagram, see Noise quantification module.
  • Noise removing, see Noise remover module, should be done after noise visualization, since the median of equidistant samples is plotted.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Time series length: Number of pings in the graphs.
    Allowed values: Time series length ≥ 1
  • Histogram span: Upper limit of plotted histogram domain in multiples of NH.
    Allowed values: Histogram span > 0
  • Median sample count: Number of equidistant samples used for finding median noise.
    Allowed values: Median sample count ≥ 0
