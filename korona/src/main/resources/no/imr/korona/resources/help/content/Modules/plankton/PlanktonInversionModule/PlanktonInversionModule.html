Plankton inversion module

Produces plankton inversion datagrams. For more about the algorithm, see plankton inversion algorithm. For more about the implemented plankton models, see plankton models. The initial size distribution is given by the plankton configuration file.

Parameters

Data settings

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Vertical unit: Unit for the height of the search window and the search columns.
  • Pings per bin: The number of pings per bin.
  • Depth samples per bin: Bin height in number of samples. Used when Vertical unit is set to SAMPLES.
  • Depth duration per bin: Bin height in milliseconds. Used when Vertical unit is set to DURATION.
  • Depth distance per bin: Bin height in meters. Used when Vertical unit is set to DISTANCE.
  • Use global noise threshold: Toggle this if the global noise threshold should be enabled. Using the global noise threshold means that the sample values for all enabled frequencies should be above the given threshold value for the sample to be used in inversion.
  • Noise threshold: The global noise threshold. See above.
  • Use min depth: If selected, then Min depth is used.
  • Min depth: Used when Use min depth is selected.
  • Use max depth: If selected, then Max depth is used.
  • Max depth: Used when Use max depth is selected.
  • Categories used for inversion: Here the user can toggle which categories (see CategorizationModule) should be used as input to plankton inversion.
  • Use all frequencies: If selected, then all frequencies are used in the inversion.
  • Active frequencies: The user can toggle which frequencies should be used in the inversion. The effect on the domain of backscatter models can be seen in the backscatter curve plot.

Inversion settings

  • Min residual error threshold: The minimal residual error. The inversion iterations for a model stops if the residual is below this value.
    Allowed values: Min residual error threshold ≥ 0
  • Max residual error threshold: The maximal residual error. The plankton sample is set to no category if the residual for the best-fit model is higher than this number.
    Allowed values: Max residual error threshold ≥ 0
  • Levenberg-Marquardt factor: The Levenberg-Marquardt factor. Used in during the inversion to give preference to the solution with the smallest norm. A higher value means that a small norm is more important than a small residual. Suggested value between 1e-6 and 1e-4.
    Allowed values: Levenberg-Marquardt factor ≥ 0
  • Max iter: The maximum number of iterations for each model inversion.
    Allowed values: Max iter ≥ 1

Plankton models

  • HardShelled: Toggle on if the hard shelled sphere model (Stanton 1994) is to be used in the inversion.
  • HardShelledR: Reflection coefficient.
  • GaseousSphere: Toggle on if the gaseous sphere model (Stanton 1994) is to be used in the inversion.
  • GasSphereG: Relative density.
  • GasSphereH: Relative sound speed.
  • FluidSpheriod: Toggle on if the fluid prolate spheroid model (Stanton 1989) is to be used in the inversion.
  • FluidSpheriodG: Relative density.
  • FluidSpheriodH: Relative sound speed.
  • FluidSpheriodBeta: Length to width ratio.
  • FluidBent: Toggle on if the fluid bent cylinder model (Stanton 1994) is to be used in the inversion.
  • FluidBentR: Reflection coefficient.
  • FluidBentS: Standard deviation of length.
  • FluidBentBeta: Length to width ratio.
  • SDWBA: Toggle on if the SDWBA model (Conti 2006) is to be used in the inversion.
  • SDWBA coeff: Select which set of SDWBA coefficients should be used (defined in Conti 2006).

Visualization

  • Show backscatter curves...: Opens a view of the backscatter curves with the current configuration of the models. The unused part of the backscatter curves will be drawn with a thinner line width than the parts that can be used given the set of frequencies and the given initial size distributions of the individuals belonging to the models.
  • Plot resolution: kA resolution of curves.
  • Plot max range: Max range in plot.
