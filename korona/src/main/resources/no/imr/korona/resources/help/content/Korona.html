KORONA

KORONA is the LSSS preprocessor, and is used for processing and visualizing data from an acoustic source. The acoustic sources may be e.g. EK60, EK500, ME70, MS70, SX90 or similar equipment.

See the getting started section for a basic introduction to using the system.
