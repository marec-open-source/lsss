KORONA cli

This section describes the KORONA command line interface (cli).

Usage:

KoronaCli <command> [options and arguments]

Print usage and list available commands:

KoronaCli --help

Print help for a specific command:

KoronaCli <command> --help

Note: If options or arguments contain spaces, then quotes are necessary, e.g. "--dir=D:\Raw files".

batch

KoronaCli batch processes files similarly to KORONA relay, but without the user interface.

Usage:

KoronaCli batch [options]

Options:

--cfs The config file settings used by the processing.
--source Directory with files to be processed.
--destination Directory where the processed files will be written.
--help Displays help information.

Example:

KoronaCli.bat batch --cfs=D:\ConfigFileSettings.cfs --source=D:\OriginalRaw --destination=D:\ProcessedRaw

calibration-generate

KoronaCli calibration-generate generates calibration.xml with values from data files.

Usage:

KoronaCli calibration-generate [options]

Options:

--help Displays help information.
--dir Directory with data files.
--output Output file as an absolute path or relative to dir. If not specified, then stdout is used.

Example:

KoronaCli.bat calibration-generate --dir=D:\RawFiles

korona-info

KoronaCli korona-info prints info about KORONA, including modules and parameters, in JSON format.

Usage:

KoronaCli korona-info

Options:

--help Displays help information.

Example:

KoronaCli.bat korona-info

print-datagrams

KoronaCli print-datagrams prints info about the datagrams in files or directories. If a directory is specified, then all files in that directory will be used. If no files or directories are specified, then the standard input is used.

Usage:

KoronaCli print-datagrams [options] [file or directory]...

Options:

--help Displays help information.
--limit Limits the number of datagrams to print.
--only Comma-separated list of datagram types to print.
--skip Comma-separated list of datagram types to not print.

Example:

KoronaCli.bat print-datagrams --skip=NME0,MRU0 D:\RawFiles\some-file.raw

work-file-to-netcdf (beta)

KoronaCli work-file-to-netcdf converts work files to NetCDF format.

Usage:

KoronaCli work-file-to-netcdf [options]

Options:

--help Displays help information.
--data-dir Directory with data files.
--delta-range The range resolution [m].
--frequency The frequency [kHz] to use, can be specified multiple times in prioritized order (default: 38).
--max-parallel Maximum parallel processes, defaulting to the number of available processors.
--max-range The maximum range [m].
--output-dir Directory where to write work files as NetCDF.
--work-dir Directory with work files.

Example:

KoronaCli.bat work-file-to-netcdf --delta-range=0.2 --max-range=1000 --data-dir=D:\RawFiles --work-dir=D:\WorkFiles --output-dir=D:\WorkFilesAsNetcdf
