Comment module

This module can be used for writing a comment about the module configuration. It can also be used for visually organizing the modules in the module editor by adding line breaks and defining collapsible module groups.

Line breaks

The parameters Line break and Vertical space can be used to add a visual separation between distinct sets of modules.

Module groups

A module group can be defined with the Start module group parameter, in which case a corresponding Group end module is automatically inserted. The modules placed between a comment module and the corresponding group end module can be visually collapsed by clicking the comment module button in the module editor. The definition of a module group and its collapsed state do not affect the operation of the modules within the group.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Start module group: This module defines the start of a collapsible group of modules.
  • Collapse module group: Visually collapses all modules until the corresponding group end module.
  • Line break: Line break before button in the module editor.
  • Vertical space: Vertical space above button in the module editor.
  • Label: Displayed on the button in the module editor.
  • Comment: The comment.
