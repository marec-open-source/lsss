Data reduction module

Removes data above and below selected ranges.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.

Upper limit

  • Blind zone: Remove data above the blind zone configured in the Transducer ranges file.
  • Min range: Remove data above this range.
  • Min depth: Remove data above this depth.

Lower limit

  • Transducer range: Remove data below the range configured in the Transducer ranges file.
  • Max range: Remove data below this range.
  • Max depth: Remove data below this depth.
  • Max below bottom: Remove data below this distance beyond the coordinated bottom detected by the Bottom detection module.
