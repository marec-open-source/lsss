RBR0: Region border datagram

This datagram contains region borders. These region borders are referred to by the Region info datagram.

Occurrences

At most once per ping per School detection module.

Source

  • School detection module.

Contents

struct Rbr0Datagram {
   DatagramHeader header; // RBR0
   int channel;           // The channel this region was detected on
   float threshold;       // The threshold [dB] used for region detection
   int borderInfoCount;   // Number of border elements
   BorderInfo borderInfos[];
};

struct BorderInfo {
   int id;           // The id of this region border, referred to by Region info datagram
   float startDepth; // Upper depth [m]
   float endDepth;   // Lower depth [m]
   float meanLogSv;  // The average Sv [dB] so far (computed on logarithmic values)
   int accepted;     // 1 if this region is currently accepted, otherwise 0
};
