Combination module

Module for generating combination echograms.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • First operand kHz: Frequency of the first operand.
    Allowed values: First operand kHz ≥ 0
  • Second operand kHz: Frequency of the second operand.
    Allowed values: Second operand kHz ≥ 0
  • First operand channel: Channel of the first operand (used if First operand kHz = 0).
    Allowed values: First operand channel ≥ 1
  • Second operand channel: Channel of the second operand (used if Second operand kHz = 0).
    Allowed values: Second operand channel ≥ 1
  • Logarithmic operands: If checked use log(sv), otherwise use (linear) sv.
  • Operation: Specifies how the operands are combined.
    Allowed values: { -, +, *, /, mean, harmonic mean, min, max, zero, copy1stOperand }
