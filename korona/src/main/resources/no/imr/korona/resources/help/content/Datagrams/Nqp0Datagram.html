NQP0: Noise quantification datagram

This datagram contains noise quantification parameters. These parameters are used later by the Noise remover module.

Occurrences

Once per ping per channel.

Source

  • Noise quantification module.

Contents

struct Nqp0Datagram {
   DatagramHeader header; // NQP0
   short channel;         // The channel to which this datagram corresponds
   float average;         // Average noise level, NE
   float upperLimit;      // Upper limit for noise values, NH
   float quality;         // The quality of the noise parameters, ranging from 0 to 100
};
