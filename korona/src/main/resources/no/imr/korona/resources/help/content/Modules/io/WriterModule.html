Writer module

This module writes processed data to .raw, .idx and .bot files.

New datagrams

  • One initial module configuration datagram, Cds0Datagram, is written to the file.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • File name: Output file name. If blank, the input file name is used.
  • Use relative directory: Whether to specify a relative or an absolute output directory.
  • Relative directory: Output directory relative to the destination directory. Used when Use relative directory is checked.
  • Directory: Absolute output directory. Used when Use relative directory is unchecked.
