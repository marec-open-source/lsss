Noise remover module

Removes noise based on parameters in noise quantification datagrams.

The noise power index N is modified for each sample:

N = N - NE if N ≥ NH
N = 0 if N < NH

where NE and NH are the noise average and upper limit.

Requirements

  • Noise quantification datagrams, Nqp0Datagram, see Noise quantification module.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Remove noise from start: Search for noise parameter datagram and use it for the first datagrams.
  • Max buffer size: Maximum buffer size in search for first noise parameter datagram.
    Allowed values: Max buffer size ≥ 0
