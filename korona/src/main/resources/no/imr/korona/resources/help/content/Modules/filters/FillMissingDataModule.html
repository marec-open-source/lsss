Fill missing data module

This module adds missing sample data.

If ping n has a channel with missing sample data, then a copy of the sample data from ping n - 1 will be added to ping n. Although sample values are copied from ping n - 1, motion data (heave, roll, pitch, heading) will that of ping n. This means that the copied sample data will be shifted vertically if the heave changes.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
