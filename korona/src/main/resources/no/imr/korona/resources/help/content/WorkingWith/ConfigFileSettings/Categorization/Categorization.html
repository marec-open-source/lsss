The edit menu

Categorization configuration

Here it is possible to define new categories with the Add button, and permanently remove categories with the Remove button.

The features known by the system can also be enabled/disabled though the panel to the right.

For each category, the following parameters can be configured:

  • Enabled: A checkbox specifying whether the category is enabled. Disabled categories become invisible to the user and will not be used in the categorization.
  • Name: The name for the category. The names for the permanent categories such as noise, bottom, etc. cannot be edited.
  • Legend: A shorter legend which is used in the colorbar when visualising results from categorization. The legend should be 5 characters or shorter.
  • Comment: An optional comment describing the category.
  • Color: The color of the category.
  • Overall a priori: The overall a priori probability of the category.
  • School a priori: Optional school a priori probability. Only used by School categorization module.
  • Geo a priori: Optional geographical a priori probability. The geographical a priori for a ping is multiplied with the overall a priori during categorization.
  • Min Sv 38: Optional minimum Sv(38 kHz). Categorization of lower values will get a linearly reduced a priori probability that reaches 0 at Min Sv 38 - Delta min max Sv 38.
  • Max Sv 38: Optional maximum Sv(38 kHz). Categorization of higher values will get a linearly reduced a priori probability that reaches 0 at Max Sv 38 + Delta min max Sv 38.
  • Requirement: Optional requirement for using the category during categorization. The requirement is a Boolean expression that must evaluate to true for the category to be used.
    • If no expression is specified, then the category is always used.
    • R18 evaluates to true if 18 kHz is available and false otherwise. Similarly, for R70, R120, etc.
    • Boolean operators such as && and || can be used.
    • The function count(Boolean...) takes any number of Boolean parameters and returns the number of parameters with value true.
    Examples:
    • Example 1: If R200 is specified for mackerel then 200 kHz must be available for anything to be categorized as mackerel. If the transducer range for 200 kHz is set to 200 m in Vertical transducer offsets then nothing will be categorized as mackerel below 200 m.
    • Example 2: R18 && count(R70, R120, R200) >= 1 specifies that 18 kHz must be available together with at least one of 70, 120 and 200 kHz.

The total a priori is calculated as

Total a priori = Overall a priori × School a priori × Geo a priori × Sv a priori.

Categorization parameters

Parameters used by the categorization system can be set here.

  • Outlier fraction: The points that lie in the percentile given by 1 minus this number are considered outliers.
  • Thinned scatter size: The maximum number of points in the point clouds used for visualization. The points used are drawn randomly from all existing points.
  • Delta min max Sv 38: Distance outside Min Sv 38 and Max Sv 38 until the a priori probability is linearly reduced to 0.

Add to category

The user can add the extracted points to a category that can be selected from a drop-down list. The category that the system deems to be the best automatically appears at the top of the list, then the second best and so on. For adding points to categories, see also Misclassification matrix.

Mark

Through this, you can mark points that meet some criteria. Possible criteria are:

  • Classified as: marks points that will be classified as the chosen category.
  • Not classified as: marks points that will NOT be classified as the chosen category.
  • Outlier: marks points that are outliers relative to the chosen category.
  • Inlier: marks points that are inliers relative to the chosen category.

Unmark

Through this, you can unmark points that meet some criteria. Possible criteria are:

  • Classified as: unmarks points that will be classified as the chosen category.
  • Not classified as: unmarks points that will NOT be classified as the chosen category.
  • Outlier: unmarks points that are outliers relative to the chosen category.
  • Inlier: unmarks points that are inliers relative to the chosen category.

Clear marking

Clears all current markings. Shortcut key: Escape.

Invert marking

Inverts all current markings.

Delete marked points

Deletes the marked points. Shortcut key: Delete.

Delete unmarked points

Deletes the unmarked points. Shortcut key: Alt-Delete.

Undo all modifications

Reads the data from file again so that all modifications before a Save are undone.

The view menu

Echogram

Shows the extracted rectangle with a separate colorbar for each frequency. The points will be masked/unmasked by dragging the colorbars. Points can also be masked by drawing rectangles directly in the echogram views. Holding Ctrl enables marking of several rectangles, and holding Alt unmarks the points inside the drawn rectangle.

Scatter

Shows a scatter plot of how the points of the categories are distributed in the feature space. A pair of feature axes can be selected by clicking the checkboxes to the left and below the plot. See also category toggles.

Frequency response

Shows the relative frequency response curves for the categories. See also category toggles.

The option 'Draw confidence interval' shows the extent of the category distributions as dashed lines. The position of the dashed lines for a frequency, e.g. 200 kHz, corresponds to the ellipse in the scatter plot projected to the axis of the corresponding feature, e.g. R200. The size of the ellipses and the position of the dashed confidence lines depend on the outlier fraction.

Probabilities

Shows the probability density function for the categories for a selected feature. See also category toggles.

Misclassification matrix

The first table shows how point cloud i, where i is the row, would be categorized if the extracted points were added as a NEW category.

The second table shows the overlap between the different point clouds, i.e. the percentage of the points in category i that lies within the 1 - outlierFraction contour of category j, where i is the row and j is the column.

This view also gives a recommendation of what can be done with the extracted points.

The user can specify different coloring schemes, depending on whether the user wishes to add the points to an existing category or create a new category. The system will then highlight the problematic values with either yellow or red color depending on the severity of the problem (yellow: somewhat severe, red: more severe).

The user can also turn on/off the enabled features (see Configuration to enable features) by clicking the toggles at the bottom of the view. The results will then be recalculated.

Rescale axes

Rescales the plot axes.

Common buttons for many views

  • Category toggles: Positioned at the top of many views. By left-clicking these toggles, the user can turn on/off the visualization of the given category. Right-clicking the toggles brings up another view where it is possible to turn on/off the use of earlier saved point clouds. By right-clicking the earlier point clouds, it is possible to delete them permanently.
