CAD0: Categorization data datagram

This datagram contains categorization data for each sample in each ping. The categories are defined in the initial categorization configuration datagram.

Occurrences

Once per ping.

Source

  • Categorization module.

Contents

struct Cad0Datagram {
   DatagramHeader header; // CAD0
   byte categoryCount;    // Number of categories per sample
   int sampleCount;       // Number of samples
   float sampleDistance;  // Vertical distance [m] between samples
   float firstDepth;      // Depth [m] of the first sample
   byte[categoryCount][sampleCount] categories;    // Category numbers defined in the Categorization configuration datagram
   byte[categoryCount][sampleCount] discriminants;
   byte[categoryCount][sampleCount] probabilities;
};

The categories array loops over all included categories and all samples. If a sample has fewer than categoryCount categories, the unknown category is used for remaining entries. The discriminants and probabilities arrays use the same ordering as the categories array.

The byte values of the discriminants and probabilities arrays represent floating point numbers between 0 and 1, converted using the formula floatValue = (0xff & byteValue) / 255.0.
