CAT0: Categorization track datagram

Result of track categorization. Refers to categories identified in the initial categorization configuration datagram, Cac0Datagram.

Occurrences

  • Once per track.

Creator

  • TrackCategorizationModule.

Contents

struct Cat0Datagram {
   DatagramHeader header; // CAT0
   byte categoryCount;    // Number of categories
   int trackId;           // Track id
   byte[categoryCount] categories;    // Category numbers defined in the Categorization configuration datagram
   byte[categoryCount] discriminants;
   byte[categoryCount] probabilities;
};
