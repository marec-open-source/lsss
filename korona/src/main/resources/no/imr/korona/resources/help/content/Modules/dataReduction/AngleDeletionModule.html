Angle deletion module

This module converts split beam data to single beam data.

Real data

For real data containing power and angles, e.g. Raw0Datagrams, the angles are simply discarded.

Complex data

For complex data containing multiple sectors with complex numbers, e.g. broadband data or narrowband data, then the sectors are reduced to a single sector such that values of Sv(f) and uncorrected TS(f) are preserved.

If yi is the complex sample value of sector i ∈ [1, n], then the replacement single beam value is computed as

y = (1 / √n) ∑ yi

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
