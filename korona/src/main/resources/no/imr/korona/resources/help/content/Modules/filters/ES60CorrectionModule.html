ES60 correction module

This module removes the ES60 triangle noise.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Reliability detection window: Window used when computing statistics used when determining best fit triangle.
  • Perform scan: Will perform a scan for the triangle index of the first ping in the next file.
  • Continue across files: Continue the current wave index number across files.
