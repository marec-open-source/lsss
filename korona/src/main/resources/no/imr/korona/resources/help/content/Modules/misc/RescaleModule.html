Rescale module

Rescales some channels to fit into the logarithmic Sv range.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Rescale channels: Which channels to rescale.
    Allowed values: { all, half, last, none }
  • Desired minimum: Desired minimum.
  • Desired maximum: Desired maximum.
  • Min max fraction: Discard this fraction of lower and upper values when deciding the rescaling.
    Allowed values: 0 ≤ Min max fraction ≤ 1
  • Initialization datagram count: Number of datagrams from each channel used to determine rescaling factors.
    Allowed values: Initialization datagram count ≥ 1
  • Initialization max ping count: Maximum number of pings to buffer up when finding rescaling factors.
    Allowed values: Initialization max ping count ≥ 1
