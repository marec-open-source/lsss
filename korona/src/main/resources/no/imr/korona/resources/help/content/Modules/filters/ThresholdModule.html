Thresholding module

This module masks out values in a specified range on individual channels.

This module sets all values ≥ Threshold to value AboveThreshold or does not change them if AboveSame is true. Similarly, it sets all values < Threshold to value BelowThreshold or does not change them if BelowSame is true.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Logarithmic values: Use log(sv) or sv.
  • Show details: Shows more detailed settings (Only last, Channels to process, Automatic depth range, Start depth, End depth).
  • Only last: When true, only the last channel is processed; if false, all channels are processed.
  • Channels to process: Process the n last channels (-1 for all channels).
  • Automatic depth range: If true and Bottom detection module is used, then the range goes to the detected seabed, if true and Bottom detection module is not used, the range goes to the max depth of the ping.
  • Start depth: Start depth in meters for the filter.
  • End depth: End depth in meters for the filter.
  • Threshold: Threshold value [dB].
  • Cut below: If selected, all samples with value < threshold will become 'Value below'. Otherwise, the sample values will remain the same.
  • Cut above: If selected, all samples with value ≥ threshold will become 'Value above'. Otherwise, the sample values will remain the same.
  • Value below: Value assigned to samples with value < threshold. The value is given in log(sv) with unit dB.
  • Value above: Value assigned to samples with value ≥ threshold. The value is given in log(sv) with unit dB.
