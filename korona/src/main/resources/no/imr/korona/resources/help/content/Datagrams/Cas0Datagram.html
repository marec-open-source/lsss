CAS0: Categorization school datagram

This datagram contains school categorization. The categories are defined in the initial categorization configuration datagram.

Occurrences

Once per region which has not been identified as multi-species.

Source

  • School categorization module.

Contents

struct Cas0Datagram {
   DatagramHeader header; // CAS0
   byte categoryCount;    // Number of categories
   int regionId;          // Region id (the first border id)
   byte[categoryCount] categories;    // Category numbers defined in the Categorization configuration datagram
   byte[categoryCount] discriminants;
   byte[categoryCount] probabilities;
};

The byte values of the discriminants and probabilities arrays represent floating point numbers between 0 and 1, converted using the formula floatValue = (0xff & byteValue) / 255.0.
