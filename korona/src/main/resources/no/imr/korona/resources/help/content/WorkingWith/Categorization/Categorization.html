The categorization library used is specified in the config file settings.

Viewing categorization results

Make sure categorization datagrams, Cac0Datagram and Cad0Datagram, are available and start playback. Right-click in one of the echogram panels and select 'Use private colormap'. Right-click in the separate colormap panel to access a colormap menu with the following extensions:

  • Category: Each pixel is colored according to its category.
  • CategoryProbability: Each pixel is colored according to its category with light intensity proportional to category conditional probability.
  • CategoryDiscriminant: Each pixel is colored according to its category with light intensity proportional to discriminant value.
  • CategoryDoubt: Each pixel is colored according to its category with light intensity proportional to the difference in discriminant value of the two best categories.
  • CategorySv: Each pixel is colored according to its category with light intensity proportional to signal strength, Sv.

The following actions are possible:

  • Left-click on a category's square in the colormap panel to toggle on and off plotting of that category. When a category is turned off, the next best category is plotted instead.
  • For category colorings that modify the light intensity (the four last choices): Drag the two markers in the colormap panel.
