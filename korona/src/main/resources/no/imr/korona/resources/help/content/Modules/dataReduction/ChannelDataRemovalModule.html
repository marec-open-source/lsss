Channel data removal module

Removes data on specified channels. The channels themselves are not removed.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Channels: Comma-separated list of channel numbers.
  • Channels from end: Comma-separated list of channel numbers from the end. (1 = last channel, 2 = second last channel, etc.)
  • Frequencies: Comma-separated list of kHz.
  • Data type: The data type to select.
  • Transmit mode: The transmit mode to select.
  • Keep specified: If selected, then keep data on only the specified channels.
