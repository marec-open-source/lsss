Median noise acceptance module

This module compares noise detected by noise detection modules to values recorded on files. If the deviation between detected and recorded noise is large, the module replaces the detected noise value with recorded noise value. The idea behind this is to avoid spikes in the detected noise by comparing the values to values recorded over larger time intervals.

The user decides which noise file to compare against. Four choices are available:

  • Check against file noise file: Checks against the median noise for the file closest in time before the time of the currently processed file.
  • Check against day noise file: Checks against the median noise for the files with date equal to the date of the currently processed file.
  • Check against survey noise file: Checks against the median noise for all the files in the survey.
  • Check against survey low-median noise file: Checks against the lowest median noise over all the files in the survey.

It is possible to check multiple of these choices, but the module will check against the first available file in the sequence file, day, survey. If, for example, all the choices are checked, the module will check against file noise if it is available. If file noise is not available, the module will check against day noise, and so on.

The comparison against noise on file is performed by computing the ratio of detected noise to recorded noise. If this ratio is outside the specified noise fraction range, the detected noise is replaced with the recorded noise.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Noise fraction range: The fraction of detected noise to recorded noise should lie within this range.
  • Use file noise file: Check the noise against file noise file, if available.
  • Use day noise file: Check the noise against day noise file, if available.
  • Use survey noise file: Check the noise against survey noise file, if available.
  • Use survey low noise file: Check the noise against survey low-median noise file, if available.
