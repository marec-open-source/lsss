Plugin module (beta)

This module uses the KORONA API for module computations. The parameter Implementation implements the ModuleComputation interface, and is compiled and used directly by KORONA. This provides a simple way to getting started and experimenting with the API.

Details about the KORONA API can be found in the Javadoc.

NB: This module is in beta and can be incompatibly changed or removed in future versions.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Example: Example implementations.
  • Implementation: An implementation of the ModuleComputation interface.
