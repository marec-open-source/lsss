Vertical transducer offsets

Vertical offset correction of transducers.

Used by the Vertical offset correction module.

The vertical offset is divided into two components. The depth coordinate component is offset due to the physical placement. A positive value means that the transducer is placed deeper than the reference depth. Note that this position can also be set in the Simrad logging software, so the offset here is considered an additional offset. The other component, PulseDelayDepthCorrection, is the offset due to pulse delay. A positive value for PulseDelayDepthCorrection is equivalent to an offset due to deeper placement of the transducer compared to the reference depth.
