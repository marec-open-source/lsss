Transducer ranges

This is a configuration file specifying the blind zone and range of each transducer.

Used by several modules, including the Bottom detection module, the Data reduction module and the Categorization module.

If data to be processed contains a channel with a frequency not specified in this file, then the blind zone and the range will be interpolated. However, no extrapolation will be done.

  • Blind zone: Interpolated to the maximum of the blind zones of the next lower and higher frequencies.
  • Range: Interpolated linearly using the ranges of the next lower and higher frequencies.
