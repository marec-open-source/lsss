NMEA

This section contains some details about the NMEA datagrams used.

Index file generation

When idx files are generated, or when a raw file without an idx file is read, these NMEA sentences are used:

  • $GPGGA: Used for longitude and latitude.
  • $GPGLL: Used for longitude and latitude, but only if no $GPGGA sentences have been read so far.
  • $GPVLW: Used for vessel distance.
  • $GPVTG: Speed is used for updating vessel distance, but only if no $GPVLW sentences have been read so far.

In some cases when a ping does not contain all necessary NMEA sentences, pings will be buffered while searching for such sentences. The buffering will be maximum 10 seconds and no more than 100 pings.

  • If the first ping does not contain any NMEA sentences with geographical position, then pings will be buffered in search for the next NMEA sentence with geographical position. If found, then that geographical position is used for the first pings, otherwise latitude and longitude are set to 0 which indicates not available.
  • If $GPVLW sentences have been read and a ping does not contain a $GPVLW sentence, then pings will be buffered in search for the next ping with a $GPVLW sentence. If found, then the vessel distance will be interpolated linearly, otherwise the vessel distance will remain the same.
    If the first ping contains a $GPVLW sentence with vessel distance zero and no more $GPVLW sentences can be found while buffering, then that $GPVLW sentence is ignored.

Heading

Vessel heading is found through NMEA sentences:

  • $GPHDT: Used for heading.

If no $GPHDT are available for a ping, then heading is interpolated from neighbouring pings.
