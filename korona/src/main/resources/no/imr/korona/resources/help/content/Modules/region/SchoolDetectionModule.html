School detection module

This module detects schools on a specified channel. The schools can be visualized in the KORONA playbox.

Use of other modules prior to the school detection can change the detected schools. Some examples:

  • To get schools with a smoother boundary, use, for example, the Smoother module.
  • To eliminate very small schools, use, for example, the Erode module followed by the Dilate module.
  • To detect schools on a combination of other channels, use, for example, the Expression module or the Combination module.

New datagrams

  • Region border datagram - One datagram for each ping containing the depth ranges detected on that ping.
  • Region info datagram - One datagram for each detected school.
  • Region table of contents datagram - One datagram in the last ping, with info about which pings contain region info datagrams.

Parameters

Detection settings

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Process last: If selected, the last channel will be used for school detection.
  • Channel: Which channel to work on, starting at 1. Used only if Process last is not selected.
  • Min depth: Minimum depth for school detection [m].
  • Max depth: Maximum depth for school detection [m].
  • Threshold: Minimum value of all samples inside a school [dB].

Acceptance settings

  • Mean Sv: Limits for average Sv in school [dB].
  • Max Sv: Limits for max Sv in school [dB].
  • Length: Limits for length of school [m].
  • Thickness: Limits for thickness of school [m].
  • Area: Limits for area of school [m²].
  • Compactness: Limits for compactness = Perimeter of circle with same area / Perimeter.

Postprocessing

  • Fill holes: If selected, then holes in detected schools will be filled.
