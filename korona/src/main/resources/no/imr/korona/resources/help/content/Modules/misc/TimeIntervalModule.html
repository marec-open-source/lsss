Time interval selection module

Module for processing only the pings in a specified time interval.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.

Time limits

  • Start date: The start date and time in UTC (dd.MM.yyyy HH:mm:ss). The empty string implies no restriction.
  • End date: The end date and time in UTC (dd.MM.yyyy HH:mm:ss). The empty string implies no restriction.

Relative ping number limits

  • Start relative ping number: The minimum relative ping number within a file, starting at 1. The empty string implies no restriction.
  • End relative ping number: The maximum relative ping number within a file, starting at 1. The empty string implies no restriction.
