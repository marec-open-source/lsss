Downsampling module

This is a module for reducing vertical resolution by downsampling. Sv is downsampled by averaging. Angles are downsampled by using the angles of the center sample in the downsample interval.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Downsampling: The method to find the downsampling factor.
  • Downsampling factor: If Downsampling = FACTOR then this is the downsampling factor.
  • Downsampling sample size: If Downsampling = SAMPLE_SIZE then the downsampling factor calculated to give approximately this sample size.
