Pulse compression filters

Used by the Pulse compression filter module.

The filters to apply to a specific channel are gathered in a channel element. Each channel element consists of one or several filter elements. The order of the filter elements defines the sequence the respective filters are applied in.

Each filter element consists, in turn of the following elements

  • decimationFactor: integer defining the downsampling factor to be applied after filtering,
  • re: real part of the filter coefficients,
  • im: imaginary part of the filter coefficients, and
  • appliesTo: (optional) element holding conditions to be fulfilled by the sent pulse in order to apply filter.

The first three elements do not need to be specified if the filter is a symbolic reference to the predefined stage filters used in standard pulse compression. Such a symbolic reference is defined by the presence of a refStage attribute in the filter element. Any decimation factor, and/or re will be ignored in this case.

The following conditions can be specified in the appliesTo tag, in all possible combinations

  • pulseForm: filter is only applied if sent pulse is of specified form. Valid values are "fm_linear_up_sweep" and, "fm_linear_up_sweep". Simrad encoding of the pulse forms as integers 1 and 5 might also be used,
  • pulseDuration: filter is only applied if sent pulse is of specified duration (in seconds),
  • minSlope: filter is only applied if the sent pulse has a slope that is greater or equal to the here defined slope, and
  • maxSlope: filter is only applied if the sent pulse has a slope that is less the here defined slope.

Example XML file

<?xml version="1.0" encoding="UTF-8"?>
<pulseCompressionFilters>
   <channel id="WBT 562907-15 ES333-7CD">
      <filter refStage="1"/>
      <filter>
         <appliesTo minSlope="1E-6" maxSlope="0.25" pulseForm="fm_linear_down_sweep"/>
         <decimationFactor>1</decimationFactor>
         <re>1,2,3</re>
         <im>4,5,6</im>
      </filter>
   </channel>
   <channel id="WBT 545609-15 ES200-3C">
      <filter refStage="1">
         <appliesTo pulseDuration="0.002048" pulseForm="1"/>
      </filter>
      <filter>
         <decimationFactor>1</decimationFactor>
         <re>1,2,3</re>
         <im>4,5,6</im>
      </filter>
   </channel>
</pulseCompressionFilters>
