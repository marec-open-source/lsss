Noise quantification module

Produces noise quantification datagrams. The datagrams contain:

  1. The average noise level.
  2. The noise upper limit.
  3. The quality of the noise estimate as a number in the range [0, 100]. The quality depends on where in the water column data representative of noise is found.

The overall procedure of this module is:

  1. Select parts of the data representative of noise.
  2. Accumulate that noise data in a histogram.
  3. Use the histogram to quantify the noise level.

Selecting noise values

The noise values input to the histogram are found ping by ping:

  1. Remove very low values
  2. Smooth the data vertically
  3. Select noise data
  4. Filter on quality
  5. Filter on threshold

The selection of noise data in a ping is done in one of these ways:

  1. Between first and second bottom echo. Quality = 100.
  2. Below a frequency-dependent deep range limit D1. Quality = 100.
  3. Between a frequency-dependent range limit D2 and the bottom. Quality in the range [50, 100].
  4. Below D2. Quality = 25.
  5. All data. Quality = 0.

Note that the definition of what it means to be above/below the first/second bottom echo may depend on the data type. For echosounder data, the first bottom echo is given by the Dep0Datagram. The second bottom echo is simply twice the range to the first bottom echo. The definition is, however, different for multibeam systems. Please look at help pages for the different data types for the definitions.

Estimating noise parameters

The selected noise data that passes the filtering on quality and threshold is accumulated in a histogram, which is used for estimating the noise parameters:

First the value NT at peak probability is found. Then NH is found at 2 to 4 standard deviations above NT, depending on noise being close to normal distributed or not. A weighting between the two possibilities is done to avoid sudden jumps in NH. Finally, NE is calculated as the average of noise values below NH.

The quality of the noise parameters is set to the average quality of the data in the histogram. If probability(NH) is not low enough compared to probability(NE), then the quality is reduced by a factor between 0.6 and 1.

Buffering of pings

There is an option for buffering pings to give more stable and representative noise values. The amount of allowable buffering is controlled by the parameter Time step buffer max size. If the size of the buffer is larger than 0, the module may buffer up to the size of the buffer before providing noise values for the first ping.

There is also an option for attempting to center noise values through the parameter Use time step buffer. When this option is enabled, the module tries to base the noise values on pings in the immediate past and the immediate future. The future pings are buffered, and the amount of buffering is controlled by Time step buffer max size.

Fallback noise

Throughout processing, the file noise.xml in the processing destination directory updated. This file is divided in 1 hour intervals, and each interval contains the noise parameters with the highest quality and the lowest value.

If not enough noise data samples are found, then the noise parameters from the closest available interval in noise.xml are used. In this case, the quality in the generated datagrams is adjusted to be in the range [10, 20], depending on the original quality in noise.xml.

Requirements

Bottom detection datagrams, for example:

  • Depth datagrams, Dep0Datagram, see Bottom detection module.

New datagrams

  • Noise quantification datagrams, Nqp0Datagram.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
  • Smooth: Type of smoothing.
    Allowed values: { none, running averager, averager }
  • Smooth interval: Number of samples to smooth vertically before making histogram.
    Allowed values: Smooth interval ≥ 0
  • Mask: Type of masking.
    Allowed values: { none, dynamic }
  • Minimum quality: Minimum quality of histogram data. The quality for each ping is set based on where the data for the histogram is picked, and then the mean quality for all data used is calculated:
    Quality = 100. Data some frequency-dependent range after first and before second bottom echo are used. Expected to be similar to passive data.
    Quality = 100. Data large frequency-dependent range(1) below transducer. Expected to be similar to passive data.
    Quality = 90. Data a frequency-dependent range(2) (range(2) < range(1)) below transducer, no detected bottom detected, and data collected down to at least 500 m below the transducer. Expected to be close to passive data.
    Quality = 75. Data some frequency-dependent range(2) (range(2) < range(1) after first and before second bottom echo are used.
    Quality = 75. Data some frequency-dependent range(2) (range(2) < range(1) below transducer. Expected to be similar to passive data.
    Quality = 50. Data below a (frequency-dependent) range from the transducer, but above the first bottom echo are used.
    Quality = 25. ata some frequency-dependent range(3) (range(3) < range(2) < range(1) below transducer. Quality = 0. All data are used.
    Allowed values: 0 ≤ Minimum quality ≤ 100
  • Threshold masking: Do not use samples with Sv values, including reflections below bottom, above the given threshold.
  • Threshold: The threshold to use for threshold masking.
  • Histogram: Type of histogram.
    Allowed values: { geometric, linear, constant }
  • Use time step buffer: Try to center noise parameters.
  • Time step buffer max size: Maximum number of time steps in buffer.
  • Histogram initialization cell count: Number of cells in the histograms at initialization.
    Allowed values: Histogram initialization cell count ≥ 1
  • Histogram maximum cell count: Maximum number of cells in the histograms.
    Allowed values: Histogram maximum cell count ≥ 1
  • Histogram initialization sample count: Minimum count of noise samples at initialization of the histograms.
    Allowed values: Histogram initialization sample count ≥ 1
  • Histogram minimum sample count: Minimum number of noise samples in the histograms.
    Allowed values: Histogram minimum sample count ≥ 1
  • Histogram smooth: Whether to smooth the probability distribution.
  • Histogram smooth factor: Diffusion time step = HistogramSmoothFactor × dx2.
    Allowed values: Histogram smooth factor > 0
  • Sdev masking: Use specified number of standard deviations as high noise limit (NH) instead of system decided standard.
  • Sdev: No stdev right of noise-pdf top (NT) to be used as high noise (NH). NB! Not used to estimate average noise NE.
  • S/N masking: Remove all values less than S/N ratio less than estimated noise.
  • S/N ratio: Minimum ratio of signal to top of noise pdf-histogram, i.e. signal/NT.
  • Use fallback noise quantile: Use lower quantile of fallback noise on file instead of calculated noise.
  • Fallback noise quantile: Lower quantile of fallback noise on file.
  • Fallback noise channels: Boolean expression using f = frequency in kHz, c = channel number, n = channel count.
