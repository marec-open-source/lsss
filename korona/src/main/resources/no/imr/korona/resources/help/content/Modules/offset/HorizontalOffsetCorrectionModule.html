Horizontal offset correction module

Module for horizontal offset correction.

The offsets are configured in the Horizontal transducer offsets part of the Config file settings.

Only the value in the field AlongCorrection is used in this module.

The corrected sv values for each transducer are computed by linear interpolation between the two closest pings. The angle values of the closest ping are used without change.

The following figure shows the positions of three consecutive pings and the alongship locations of two transducers labelled X and Y at the time of those pings. The colors indicate which pings will be used for computing the corrected values in ping B.

The corrected sv values for transducer X in ping B will use linear interpolation between the sv values in pings B and C, located at XB and XC in the figure above.

The corrected sv values for transducer Y in ping B will use linear interpolation between the sv values in pings A and B, located at YA and YB in the figure above.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.
