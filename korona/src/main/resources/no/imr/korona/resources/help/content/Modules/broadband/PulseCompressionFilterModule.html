Pulse compression filter module

This module allows applying a custom filter chain to broadband data.

Each element of the filter chain is a convolution filter specified through its coefficients. Additionally, downsampling can be applied at each step of the chain. Individual elements of the filter chain can be made conditional, based on certain parameters of the sent pulse.

Parameters

  • Active: If the module is not active, then all datagrams pass unaltered through it.

Configuration file

This module requires a configuration file containing the different filters to apply, grouped by channel.

For a specific channel, the order of filters is defined by their sequence in the configuration file. Note that, while the convolution is a commutative operation, a filter with decimation will influence the frequency response of the filters applied later in the filter chain. Hence, only adjacent filters without downsampling may be permuted.

There exist two types of filters:

  • Stage reference filters: a symbolic reference to the predefined stage filters used in pulse compression with implicitly defined coefficients and decimation factor, and
  • Arbitrary filters: filters where the coefficients and decimation factor need to be defined explicitly in the configuration file.

In addition, each filter can be switched on and off, based on conditions the sent pulse needs to fulfill, defined in the optional appliesTo element of the filter definition. Any of the following conditions may be imposed:

  • Pulse form: filter is only applied if sent pulse is of specified form,
  • Pulse duration: filter is only applied if sent pulse is of specified duration (in seconds),
  • Minimal pulse slope: filter is only applied if the sent pulse has a slope that is greater than or equal to the here defined slope, and
  • Maximal pulse slope: filter is only applied if the sent pulse has a slope that is less than the here defined slope.
